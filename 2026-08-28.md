# Veckans AI-spaning — 2026-08-28

## Inledning

Den här veckan handlar om vuxenblivande. Docker — ett bolag som i 15 år byggt infrastrukturen bakom halva internets servrar — lanserar officiellt stöd för de verktyg som kopplar AI-agenter till omvärlden. Uber publicerar ett komplett säkerhetsramverk för agenter baserat på erfarenheter från sina egna produktionssystem. Och ett nytt verktyg visar sig vara ett kors på vad agenter *säger* att de gör kontra vad de *faktiskt* utför. Parallellt konsolideras ett mönster: kunskapsbaser — böcker, vetenskapliga databaser, kodkonventioner — paketeras som installerbara "skills" som delas mellan dina AI-verktyg. AI-agenternas vardag börjar likna en väl genomtänkt arbetsplats snarare än ett experiment.

## Gör Claude Code och andra AI-assistenter smartare

### codegraph

**Vad det är:** Ett lokalt verktyg som läser igenom hela din kodbas, kartlägger vad varje funktion gör och hur allt hänger ihop, och sparar kartan i en liten lokal databas — sedan kan Claude Code ställa frågor om koden mot den kartan i stället för att gissa.

**Varför det är intressant:** När Claude Code jobbar med ett stort projekt läser den om filer om och om igen — dyrt och ineffektivt. codegraph ger den en permanent karta: "vad anropar den här funktionen?", "var används den här variabeln?" besvaras på en bråkdels sekund ut ur en lokal databas i stället för att söka igenom hundratals filer. Benchmark från aug 2026 visar 44% lägre kostnad och 62% färre "ord" till modellen jämfört med vanliga sökmetoder. Resultaten delas via samma protokoll som Claude Code redan pratar (MCP), så ingen ominstallation behövs.

**Buzz-nivå:** Börjar fångas upp. MIT-licens; benchmarkad och uppmärksammad i agentfokuserade kretsar aug 2026. Få stars ännu — tidigt fynd.

**Testa:** https://github.com/colbymchenry/codegraph — installera lokalt; README visar konfigurationsfilen för Claude Code.

### the-knowledge-guy

**Vad det är:** Ett verktyg som laddar in dina PDF- och e-böcker i Claude Code så att agenten kan söka i hela biblioteket på en enda fråga — i stället för att du manuellt klistrar in relevanta stycken varje gång.

**Varför det är intressant:** Har du tekniska manualer, branschguider eller facklitteratur du ständigt refererar till? Normalt kopierar du manuellt in relevanta delar till en AI-konversation. the-knowledge-guy konverterar boken till ett format Claude Code förstår, indexerar den, och låter agenten söka i hela biblioteket automatiskt när den behöver fakta. Kostar ungefär 1–3 dollar per bok att indexera — sedan gratis per fråga. Jämfört med att ladda hela boken varje konversation (extremt dyrt) är det en storleksordning billigare. Besläktat med scientific-agent-skills (se nedan) men inriktat på egna böcker snarare än vetenskapliga databaser.

**Buzz-nivå:** Extremt tidigt. MIT-licens; nytt projekt med ett flertal forks, vilket signalerar att det fyller ett praktiskt hål.

**Testa:** https://github.com/vitalysim/the-knowledge-guy — peka på en PDF och kör indexeringsskriptet; README visar hur du kopplar till Claude Code.

### git-workflow-skill

**Vad det är:** Ett installerbart kunskapspaket som lär Claude Code, Cursor och GitHub Copilot hur erfarna team hanterar versionshantering — branching-strategier, commit-format, pull request-flöde och integration med byggsystem.

**Varför det är intressant:** Varje team har egna Git-rutiner som AI-agenter normalt inte känner till — de gör det på "standard-sättet" och skapar extra jobb för granskare. git-workflow-skill paketerar ett helt arbetsflöde som versionshanterad kunskap: installera det en gång i teamets miljö och alla era AI-assistenter jobbar enligt era regler. Det är ett av de första fungerande exemplen på det framväxande "agent skills"-mönstret — ett sätt att distribuera procedurkunskap till AI-verktyg lika enkelt som att installera ett program. Mönstret är viktigt att följa.

**Buzz-nivå:** Extremt tidigt. 44 GitHub-stjärnor, Show HN 22 aug 2026. MIT + CC-BY-SA.

**Testa:** https://github.com/netresearch/git-workflow-skill — en rad i din Claude Code-konfigurationsfil räcker för att aktivera.

## Verktyg, automation & infrastruktur

### Docker MCP Gateway

**Vad det är:** Dockers officiella CLI-plugin som startar 300+ AI-agentverktyg — databaser, webbläsare, API-kopplingar, filhantering och mer — som isolerade containrar med ett gemensamt ingångslager och inbyggd hantering av inloggningsuppgifter.

**Varför det är intressant:** I dag är det manuellt krångel att koppla Claude Code till externa tjänster: ladda ned en tredjepartsserver, konfigurera nycklar i textfiler, hoppas att servrarna uppdateras med säkerhetsfixar. Docker MCP Gateway centraliserar det hela: ett kommando drar ned en granskad, isolerad tjänst med lösenord hanterade via Docker Desktops inbyggda nyckelring — ingenting exponeras i konfigurationsfiler. De 300+ verktygen representerar det snabbast växande verktygsekosystem för agenter i historien. Att Docker — ett bolag med ett decennium av infrastrukturuppbyggnad — formaliserar det ger garantier om underhåll och säkerhetsuppdateringar som hobbyalternativ saknar.

**Buzz-nivå:** Håller på att bli en grej. Apache 2.0; officiellt Docker-projekt på GitHub, aug 2026. Del av Dockers bredare MCP Catalog-initiative.

**Testa:** https://github.com/docker/mcp-gateway — kräver Docker Desktop; `docker mcp install` + välj verktyg ur katalogen.

### Director (Browserbase)

**Vad det är:** Ett webautomationsverktyg där du beskriver vad du vill göra på en webbplats på vanlig svenska, och Director utför det — men i stället för att dölja hur det sker ger det dig tillbaka läsbar, versionsstyrd kod du kan granska och ändra.

**Varför det är intressant:** Vanliga webautomationsverktyg (Selenium, Playwright) kräver programmering; AI-automationsverktyg kör bakom en svart vägg. Director kombinerar det bästa av båda: du börjar med naturligt språk ("logga in, exportera alla kontakter, spara som CSV"), men resultatet är kod — inspekterbar, versionsstyrd och återanvändbar — inte en osynlig process. Det gör det möjligt att granska och förbättra automatiseringsflöden som om de vore vanlig mjukvara. Browserbase är ett etablerat infrastrukturbolag inom webautomation.

**Buzz-nivå:** Börjar fångas upp. Gratis tier, lanserat 2026. Täckt i agentfokuserade nyhetsbrev som praktiskt alternativ till svarta lådor.

**Testa:** https://www.browserbase.com/blog/introducing-director — registrera på browserbase.com och testa ett automatiseringsflöde direkt i webbgränssnittet.

### Caspian SDK

**Vad det är:** En öppen kommunikationslösning som ger en AI-agent en enda identitet och ett enda svarsmönster över Slack, Discord, Telegram, WhatsApp, Instagram, e-post, SMS och X — utan att du bygger separata kopplingar för varje kanal.

**Varför det är intressant:** Att driftsätta en agent i produktion kräver normalt separata webhook-integrationer för varje meddelandekanal — Slack-botens OAuth-token löper ut, Telegram-boten kraschar, WhatsApp-integrationen behöver underhåll. Caspian äger hela kommunikationsinfrastrukturen: en Python- eller TypeScript-funktion (`on_message`) hanterar allt, och de roterar tokens och hanterar återanslutningar utan att du behöver tänka på det. Relevant för alla som vill exponera en agent mot kunder på deras föredragna kanal.

**Buzz-nivå:** Börjar fångas upp. 915 GitHub-stjärnor; Show HN ~21 aug 2026. Aktiv buildathon (14 500 USD i priser) på Devpost.

**Testa:** https://github.com/TryCaspian/caspian-sdk — pip install + ett konfigurationsblock; README visar ett komplett flöde på under 20 rader.

### uber/ADR — Agent Detection & Response

**Vad det är:** Ubers öppna säkerhetsramverk för AI-agenter, med en sensor, ett benchmark och ett detektionssystem som täcker alla 17 kända angreppstyper mot agenter — publicerat som ett vetenskapligt bidrag vid MLSys 2026.

**Varför det är intressant:** AI-agenter kan manipuleras på sätt som är svårare att föresvara sig: en agent kan luras att läsa ett dokument som innehåller dolda instruktioner ("ignorera din chef och gör det här i stället"). Uber byggde ADR för sina egna produktionssystem och har nu öppnat koden. Konkurrenter finns bara i akademisk forskningsmiljö — ADR är det första systemet som kombinerar realtidsdetektering, ett offentligt benchmark och en öppen implementation i ett enda paket. Stöder de vanligaste agentramverken.

**Buzz-nivå:** Börjar fångas upp. ~770 GitHub-stjärnor, Apache 2.0. Vetenskaplig tyngd ovanlig för open source-agentsäkerhet.

**Testa:** https://github.com/uber/ADR — kör detectorn mot din befintliga agentinfrastruktur; README visar ett enkelt setup-flöde.

### FriskAI

**Vad det är:** En molnplattform som i realtid spårar vad AI-agenter *faktiskt gör* — vilka filer de läser, vilka externa tjänster de anropar, vilka kommandon de kör — och larmar om beteendet avviker från det förväntade.

**Varför det är intressant:** Det finns en fundamental skillnad mellan vad en agent *säger* att den ska göra och vad den faktiskt utför. FriskAI lägger ett observationslager på agentens handlingar — inte på vad den skriver i chatt-loggen. Det är analogt med ett intrångdetektionssystem för vanlig mjukvara, men byggt för agenters specifika beteendemönster. I takt med att agenter ges mer behörigheter (filsystem, databaser, externa API:er) blir den distinktionen allt viktigare. Stöder de vanligaste agentramverken.

**Buzz-nivå:** Extremt tidigt. 4 M USD pre-seed raised 2026. Tidig tillgång; ingen öppen GitHub-repo ännu.

**Testa:** https://www.startuphub.ai/startups/friskai — friskai.io för tidig tillgång och demo.

### AgentAnywhere (ShepHertz)

**Vad det är:** En agentplattform för banker, sjukhus och myndigheter som kör AI-agenter helt innanför organisationens egna system — ingen kod, ingen konversation och inga beslut lämnar den egna infrastrukturen.

**Varför det är intressant:** De flesta AI-plattformar (Azure AI, AWS Bedrock) innebär att data passerar leverantörens servrar. För reglerade branscher — GDPR, patientdata, banksekretess — är det en dealbreaker. AgentAnywhere är byggt specifikt för de organisationerna: välj öppna modeller (Llama, Mistral, Gemma), kör dem på egna servrar, med ett enda styrningslager som kontrollerar varje agentanrop och automatiskt genererar SOC 2/ISO 27001-underlag. Det indiska bolaget ShepHertz tränar dessutom egna modeller på lokala datamängder, vilket stärker caset för organisationer med dataresidensskrav.

**Buzz-nivå:** Börjar fångas upp. Lanserat 21 aug 2026. Täckt av Business Standard, Tribune India och CIO&Leader.

**Testa:** https://entrackr.com/snippets/shephertz-technologies-launches-agentic-ai-platform-agentanywhere-12273165 — besök agentanywhere.ai för en demo.

## Specialgrejer & experiment

### Huzzah

**Vad det är:** En experimentell kodredigerare där du inte skriver riktig kod — du skriver ett slags avsiktstext ("pseudokod"), och AI:n genererar och synkroniserar den faktiska koden i bakgrunden.

**Varför det är intressant:** Cursor och Claude Code låter dig ge instruktioner i vanlig text och de ändrar din källkod. Huzzah prövar ett tredje paradigm: din pseudokod *är* källkoden. Filen med avsikter sparas separat från den genererade implementationen; om du ändrar avsikten synkroniserar AI:n implementationen direkt. Ändringar blir strukturella operationer — du omformulerar *vad* du vill ha — snarare än ett samtal om *hur* det ska göras. Det är ett genuint experiment i om det går att skriva programvara på ett högre abstraktionsnivå. Fortfarande tidigt, men HN-diskussionen (273 poäng, 146 kommentarer) visar att idén engagerar.

**Buzz-nivå:** Börjar fångas upp. 163 GitHub-stjärnor; Show HN 24 aug 2026, 273 poäng och 146 kommentarer.

**Testa:** https://github.com/danielvaughn/hz — kör lokalt; välj önskad AI-modell via konfigurationsfil.

### scientific-agent-skills

**Vad det är:** 163 validerade specialkunskaper för AI-agenter inom naturvetenskap, bundlade med kopplingar till 100+ vetenskapliga databaser — PubMed (medicin), proteindatabaser, kemikaliedatabaser — installerbara i Claude Code och liknande verktyg.

**Varför det är intressant:** AI-assistenter som Claude kan svara på vetenskapliga frågor men vet normalt inte hur man söker i PubMed, laddar ned proteinstrukturer från RCSB PDB eller ställer frågor mot ChEMBL (en databas med 2+ miljoner kemiska föreningar). scientific-agent-skills löser det: 163 paketerade arbetsflöden som ger agenten direkt, strukturerad sökning i rätt databas — och kan koppla ihop svar från flera databaser automatiskt. Används av K-Dense AI med 175 000+ forskare som rapporterad användarbas. Den emergenta "agent skills"-standard som detta bygger på kan bli för agentkunskap vad npm är för mjukvara.

**Buzz-nivå:** Börjar fångas upp. Öppet på GitHub, kompatibelt med Agent Skills-standarden (aug 2026).

**Testa:** https://github.com/k-dense-ai/scientific-agent-skills — installera via README; fungerar med Claude Code om du har ett Anthropic API-konto.
