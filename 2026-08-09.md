# Veckans AI-spaning — 2026-08-09

## Inledning

Den här veckan domineras av en tydlig trend: att göra AI-agenter till ett verktyg som *hela organisationen* kan använda, inte bara ingenjörer. Cloudflare open-sourcar sin interna agent-plattform efter att tusentals anställda — marknadsfolk, support, analytiker — använt den sedan maj. Product Hunt fylls av "agent-OS:ar" med inbyggda mänskliga godkännandeflöden. Och en ny kategori växer fram med kraft: *cross-agent memory* — tjänster som ser till att Claude Code, Cursor och Codex delar samma kontext utan att du behöver förklara om dig varje gång du byter verktyg. Parallellt stärks säkerhetsskiktet: tre separata projekt täcker nu runtime-skydd för agenter (HiddenLayer, Parallax, Prediction Guard), med extra tryck från EU AI Act som trädde i kraft 2 augusti.

## Gör Claude Code och andra AI-assistenter smartare

### Atlaso

**Vad det är:** Ett minneslager som automatiskt synkar din kontext — projekt, regler, preferenser — mellan Claude Code, Cursor, Codex och tre andra AI-verktyg.

**Varför det är intressant:** I dag är varje AI-verktyg ett separat minne. Byter du från Claude Code till Cursor försvinner allt: vad du håller på med, hur din kod är strukturerad, vilka beslut du fattat. Atlaso löser detta med ett centralt minneslager som alla anslutna verktyg läser ifrån — som om dina AI-assistenter plötsligt pratade med varandra. Jämfört med att manuellt klistra in kontextfiler i varje nytt verktyg är det ett ordentligt kliv framåt.

**Buzz-nivå:** *Håller på att bli en grej* — ca 250 Product Hunt-röster vid lansering 6 aug 2026; 6 verktyg stödda från dag ett.

**Testa:** Sök "Atlaso cross-agent memory" på producthunt.com — installera plugin för Claude Code och ett annat AI-verktyg du redan använder.

### swarm-forge

**Vad det är:** Robert C. Martin ("Uncle Bob", mannen bakom programmeringsklassikern *Clean Code*) bygger ett system för att koordinera flera AI-agenter med ingenting mer avancerat än terminalfönster och git.

**Varför det är intressant:** De flesta multi-agent-system är komplexa plattformar med egna servrar och dashboards. swarm-forge är medvetet primitivt: agenter (specifier, coder, refactorer, architect, QA) kommunicerar via textfiler i isolerade git-mappar och koordineras via tmux-rutor. Inga frameworks, inga molntjänster. Resultatet är full observabilitet — du ser exakt vad varje agent gör i exakt vilket ögonblick. Viktigt perspektiv i en bransch som tenderar att stapla abstrakta lager ovanpå varandra.

**Buzz-nivå:** *Börjar fångas upp* — 2 000 GitHub-stjärnor, +504 senaste veckan (vecka 32 2026); Uncle Bob delar löpande uppdateringar på X.

**Testa:** https://github.com/unclebob/swarm-forge — kräver terminal, men README är pedagogisk.

### HAR — Harness for Agent Racing

**Vad det är:** En öppen ramverk som låter Claude Code, Cursor, Codex och andra AI-agenter jobba på *samma problem parallellt*, varje agent i sin egna isolerade kopia av koden, och sedan jämföra resultaten.

**Varför det är intressant:** Tänk som en tävling: ställ in ett problem, starta fem agenter, se vem som löser det bäst. Varje agent avslutar med ett kryptografiskt bevis — ett digitalt kvitto — på exakt vad den gjort, transparent och verifierbart. Jämfört med att köra en agent i taget och hoppas på det bästa är detta ett systematiskt sätt att höja kvaliteten och bygga förtroende för outputen.

**Buzz-nivå:** *Börjar fångas upp* — ca 118 Product Hunt-röster vid lansering 9 aug 2026; agent-agnostiskt (fungerar med valfri agent).

**Testa:** Sök "HAR harness agent racing" på Product Hunt eller GitHub.

### FreeBuff

**Vad det är:** En gratis coding agent — helt utan prenumeration eller API-nyckel — med fem ingångar (desktop-app, terminal, webb, moln och chatt), finansierad via utvecklarriktade annonser.

**Varför det är intressant:** Alla seriösa coding agents (Claude Code, Codex, Cursor) kostar pengar, antingen per månad eller per förfrågan. FreeBuff vänder på modellen: du ser relevanta annonser, agenten är gratis. Stöder flera AI-modeller inkl. DeepSeek V4, GPT-5.6 Luna och Kimi K2.7 Code via samma gränssnitt. Enkel ingångspunkt utan ekonomisk risk för den som vill prova AI-assisterat arbete.

**Buzz-nivå:** *Håller på att bli en grej* — 8 700 GitHub-stjärnor; 185 000 registrerade användare rapporterat (vecka 32 2026).

**Testa:** https://github.com/CodebuffAI/freebuff

## Verktyg, automation & infrastruktur

### Soloop

**Vad det är:** En "approval-first Agent OS" — ett AI-team (VD, CTO, CMO) som arbetar autonomt mot ett gemensamt mål och bara eskalerar de beslut som genuint kräver mänskligt omdöme.

**Varför det är intressant:** De flesta AI-verktyg svarar på en fråga i taget. Soloop är annorlunda: du ger det ett mål ("öka konverteringen på landningssidan 20%") och ett koordinerat AI-lag tar sig an uppgiften med delat minne och tydlig ansvarsfördelning. Mänskliga godkännandeportar kan läggas in exakt där du vill ha kontroll — resten rullar autonomt. Riktar sig mot solo-grundare men principen fungerar för vem som helst som vill delegera mer till AI.

**Buzz-nivå:** *Håller på att bli en grej* — ca 479 Product Hunt-röster vid lansering 9 aug 2026.

**Testa:** Sök "Soloop Agent OS" på producthunt.com för early access.

### Cloudflare OS + Kitesurf

**Vad det är:** Cloudflares hela interna agent-plattform, open-sourcat under "Agents Week" (5 aug): ett browser-baserat workspace, ett säkerhetslager kallat Gatekeepers, och personliga mini-appar som körs direkt i molnet — plus "Kitesurf", en agent-optimerad webbläsare skriven i Rust med 3–7 gånger lägre minnesanvändning än Chrome.

**Varför det är intressant:** Det är sällsynt att ett teknikbolag av Cloudflares storlek open-sourcar sin interna AI-infrastruktur. Plattformen har testats av tusentals anställda — inte bara ingenjörer — sedan maj 2026, vilket innebär ovanligt hög mognadsgrad för ett open source-verktyg i detta stadium. Kitesurf är specifikt designad för AI-agenter som *primäranvändare* (inte människor), vilket gör den intressant för den som kör agenter som behöver navigera webben.

**Buzz-nivå:** *Håller på att bli en grej* — bloggpost 5 aug genererade ~40 följdartiklar på en vecka; Kitesurf fick ca 137 Product Hunt-röster.

**Testa:** blog.cloudflare.com/cloudflare-os — kräver Cloudflare-konto för deployment.

### Murmell

**Vad det är:** En delad molncanvas där Claude Code, Codex, Kimi och andra AI-agenter jobbar *synkront* i samma kodbas — och fortsätter arbeta även när du stänger laptopen.

**Varför det är intressant:** När du stänger Claude Code stannar allt. Murmell är ett persistenslager: agentarbetet lever i molnet, inte i din terminal. Flera agenter kan "claima" olika filer — som att boka ett konferensrum — och arbeta parallellt utan att trampa på varandra. Liknar att ha ett team av AI-assistenter med ett eget kontor de kan använda oberoende av dig.

**Buzz-nivå:** *Börjar fångas upp* — ca 110 Product Hunt-röster vid lansering 3 aug 2026.

**Testa:** Sök "Murmell shared canvas agents" på Product Hunt.

### Finyuus

**Vad det är:** Ett textuellt programmeringsspråk för att bygga AI-arbetsflöden som tål att servern kraschar mitt i körningen — byggt på plattformen Temporal som används av Uber och Stripe för processer som måste bli klara oavsett vad.

**Varför det är intressant:** De flesta AI-automationsverktyg tappar tillståndet om något går fel: en nättimeout, ett serveromstart — och hela jobbet börjar om från noll. Finyuus hanterar detta med "varaktig körning" som automatiskt fortsätter precis där det slutade. Inbyggda mänskliga godkännandeportar gör det möjligt att designa arbetsflöden där du bestämmer *exakt* var du vill bli tillfrågad. Koden är textfiler som kan versionhanteras med git.

**Buzz-nivå:** *Börjar fångas upp* — ca 88 Product Hunt-röster (6 aug 2026); open source, AGPL-licens.

**Testa:** Sök "Finyuus Temporal AI workflows" på Product Hunt eller GitHub.

### HiddenLayer Agent Harness Security

**Vad det är:** En säkerhetslösning som kopplar in sig i coding agents egna hook-system och blockerar prompt injection, hemlighetsläckage och farliga kommandon i realtid — utan att trafiken behöver gå via en separat server.

**Varför det är intressant:** De flesta säkerhetslösningar för AI-agenter sitter utanför agenten och avlyssnar nätverkstrafik. HiddenLayer gör tvärtom: det kopplar in sig *inuti* Claude Code, Cursor och GitHub Copilot via deras egna hook-API:er. Skyddet aktiveras *innan* agenten skickar ett kommando — inte efter. Designad för organisationer som behöver kontrollera och logga vad deras AI-agenter faktiskt gör i produktionsmiljöer.

**Buzz-nivå:** *Börjar fångas upp* — lanserades 3 aug 2026; HiddenLayer är ett etablerat bolag inom AI-säkerhet med befintliga enterprise-kunder.

**Testa:** hiddenlayer.com/news/hiddenlayer-unveils-agent-harness-security

### Prediction Guard

**Vad det är:** En drop-in-proxy som sätter sig framför din AI-trafik och filtrerar prompt injection, anonymiserar personuppgifter och loggar ett revisionsflöde — designad specifikt kring EU AI Act, nu tillgänglig som self-hosted lösning via AWS.

**Varför det är intressant:** EU AI Act trädde i kraft 2 aug 2026. Prediction Guard är byggd för att uppfylla kraven direkt ur kartongen: revisionslogg, PII-filtrering och compliance-rapportering i ett paket. Air-gapped deployment (helt frånkopplad från internet) är möjlig — relevant för sjukvård, juridik och offentlig sektor. Jämfört med att bygga compliance-lagret internt är det en väsentlig genväg.

**Buzz-nivå:** *Börjar fångas upp* — ny AWS Marketplace-tillgänglighet via Carahsoft (jul 2026); timing precis efter AI Acts ikraftträdande ger stark medvind.

**Testa:** predictionguard.com

### Crunchbase MCP

**Vad det är:** Crunchbase — världens ledande databas för investeringar och startups — tillgänglig direkt i Claude och andra AI-verktyg via MCP-protokollet.

**Varför det är intressant:** Sätter ett viktigt mönster: en stor, proprietär databas distribueras nu som ett "verktyg" som AI-agenter kan anropa direkt under en konversation. I praktiken: du kan fråga Claude "vilka SaaS-bolag i Norden fick Series A förra kvartalet?" och få svar baserat på Crunchbases realtidsdata — utan att lämna chatten. 84 % träffsäkerhet på finansieringsprediktioner uppges. Crunchbase är troligen den första stora dataplattformen som gör detta; fler förväntas följa.

**Buzz-nivå:** *Börjar fångas upp* — pressrelease 21 jul 2026; att Crunchbase — ett etablerat bolag — kliver in som MCP-aktör legitimerar protokollet ytterligare.

**Testa:** about.crunchbase.com/press/press-releases/crunchbase-launches-mcp — kräver Crunchbase-konto.

## Specialgrejer & experiment

### Parallax

**Vad det är:** En Rust-baserad säkerhetsbinär som placeras som en osynlig vakt framför AI-agents nätverkstrafik och blockerar hot på bråkdelen av en sekund — 54 inbyggda regler i 13 hotkategorier, utan externa beroenden.

**Varför det är intressant:** En enda statisk fil, inga beroenden. Kan köras som HTTP-endpoint eller transparent proxy mot LLM-API:er. Täcker prompt injection, datautfiltrering, rekognoscering, PII-läckage och supply chain-attacker — allt med evalueringsmotorer som kan kombineras. Akademisk bakgrund (arXiv-paper "Parallax: Why AI Agents That Think Must Never Act", april 2026) ger metodologisk trovärdighet. Extremt tidigt men pekar på en viktig kategori: runtime policy enforcement som agentramverk sällan erbjuder.

**Buzz-nivå:** *Extremt tidigt* — 32 GitHub-stjärnor; arXiv-paper april 2026; nämnd i HN runtime security-diskussion.

**Testa:** https://github.com/agent-defense/parallax
