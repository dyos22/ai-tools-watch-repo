# AI-verktygs-spaningen — 9 oktober 2026

## Inledning

Den här veckan handlar det om infrastruktur: hur man kör, koordinerar, distribuerar och ger minne till AI-agenter. Docker tar klivet in i agentvärlden med ett officiellt verktyg. Två projekt tävlar om att bli standardsättet att samköra flera kodningsagenter parallellt. En nyfinansierad startup sätter sig på att göra AI-agenter lika naturliga i iMessage och WhatsApp som ett SMS. Och ett par verktyg löser det problem som irriterar de flesta som använder Claude Code dagligen: att agenten glömmer allt varje gång du stänger terminalen.

## Topp 3 att testa direkt

1. **openrig** — starta ett helt team av Claude Code, Codex och Pi med en enda YAML-fil istället för fem separata terminaler.

## Gör Claude Code och andra AI-assistenter smartare

### obsidian-mind — minnet som överlever sessionens slut

**Vad det är:** En vault-template (tänk: ett strukturerat anteckningsblock) som ger Claude Code, Codex och Gemini CLI persistent minne mellan sessioner via ett MCP-tillägg.

**Varför det är intressant:** Varje gång du startar en ny Claude Code-session börjar den från noll — den vet ingenting om vad ni jobbade med igår, vilka beslut ni tog, eller varför en viss lösning valdes. obsidian-mind fixar det: sessionshooks injicerar kontext automatiskt vid start, och en inbyggd MCP-server gör minnet tillgängligt för agenter i vilka repositories som helst. Jämfört med claude-mem (som fokuserar på att komprimera text) är obsidian-mind designat för mänsklig läsbarhet — du kan öppna anteckningarna i Obsidian-appen och läsa eller redigera dem precis som ett vanligt dokument.

**Buzz-nivå:** Håller på att bli en grej — 4 974 stjärnor på GitHub, 560 forks visar att folk faktiskt använder det, +168 stjärnor under senaste veckan.

**Testa:** https://github.com/breferrari/obsidian-mind — installera Obsidian, klona repot som din vault och aktivera MCP-servern.

### autoharness — Claude Code lär sig av dina egna sessioner

**Vad det är:** Ett plugin till Claude Code som automatiskt plockar upp och sparar "skills" (återanvändbara instruktioner) från dina riktiga sessioner — utan att du behöver skriva dem för hand.

**Varför det är intressant:** Claude Code kan styras med skills-filer som berättar hur den ska bete sig i ett specifikt projekt. Problemet är att dessa filer snabbt föråldras och är tråkiga att underhålla manuellt. autoharness löser det: en reflektions-pipeline fångar vad som faktiskt fungerat i dina sessioner, slår ihop dubbletter och rensar bort det som inte längre används — utan att röra sådant du skrivit för hand. Inget annat känt verktyg hanterar den livscykeln automatiskt för Claude Code.

**Buzz-nivå:** Börjar fångas upp — Product Hunt-lansering i oktober 2026, listat i flera verktygsindex. Siffror inte heltäckande verifierade ännu.

**Testa:** https://www.producthunt.com/posts/1216659 — sök tigerless-labs på GitHub för installationsinstruktioner.

### REA ("Reverse Engineer Anything") — analysera program utan källkod, direkt i din agent

**Vad det är:** Ett MCP-tillägg som ger Claude Code och andra agenter förmågan att analysera program-binärer, Android-appar och firmware — som att ge agenten ett "röntgenöga" för program som saknar källkod.

**Varför det är intressant:** Ibland behöver man förstå hur ett program fungerar utan att ha tillgång till koden — en gammal intern app, ett tredjepartsbibliotek, en firmware-fil. REA kopplar in professionella analysverktyg (Ghidra, JADX, Binwalk) direkt i Claude Codes workflow, så att agenten kan återskapa pseudokod och spåra beteenden utan att du behöver byta fönster. Version 4.0–4.1 (4–6 okt 2026) lade till stöd för Android-APK:er och firmware. Avsett för auktoriserade säkerhetsanalyser och research.

**Buzz-nivå:** Håller på att bli en grej — nära 9 000 GitHub-stjärnor, varav ~3 000 tillkom på en enda dag. Version 4.1 publicerad 6 oktober 2026.

**Testa:** https://github.com/morluto/rea — `npx @morluto/rea` kopplar tillägget till Claude Code.

## Verktyg, automation & infrastruktur

### openrig — ett helt agentteam med en YAML-fil

**Vad det är:** Ett ramverk för att starta och koordinera ett team av AI-kodningsagenter (Claude Code, Codex, Pi) som jobbar parallellt på samma projekt.

**Varför det är intressant:** Att köra flera agenter parallellt innebär normalt kaotiska terminalfönster, konflikter i git och ingen central överblick. openrig löser det: du beskriver ditt "team" i en YAML-fil (en lead-agent som delegerar till specialister), startar allt med ett kommando, och agenterna kommunicerar med `rig send`/`rig broadcast`. Hela teamet kan snapshotttas och återstartas. Sticker ut från abstrakta ramverk som CrewAI och AutoGen genom att vara byggt specifikt för de verktyg folk faktiskt använder till vardags.

**Buzz-nivå:** Håller på att bli en grej — 6 212 stjärnor totalt, +2 693 under senaste veckan, på GitHub Trending (alla språk) vecka 40.

**Testa:** https://github.com/mvschwarz/openrig — `npm install -g @openrig/cli`, definiera ditt team i en YAML-fil, kör `rig start`.

### Docker Agent — paketera och dela agenter precis som container-images

**Vad det är:** Officiellt tillägg till Docker (som du kanske redan har) för att definiera, köra och dela AI-agenter via vanliga container-registries — samma system som används för att distribuera webbappar och databaser.

**Varför det är intressant:** Tänk dig att dela en AI-agent som du delar en webbapp med Docker: `docker agent push` och mottagaren kör `docker agent pull` och får exakt samma agent med samma verktyg, miljövariabler och beroenden. Det löser reproducerbarhets- och distributionsproblemet i agentvärlden — idag vet man sällan om "din" agent och "min" agent beter sig lika. Stödjer MCP-verktyg, A2A-protokollet och alla stora AI-providers. Kräver Docker Desktop 4.63+ (beta).

**Buzz-nivå:** Håller på att bli en grej — 4 300 stjärnor, 495 forks, 296 HN-poäng och 137 kommentarer i diskussionstråden.

**Testa:** https://github.com/docker/docker-agent — `docker agent init` för att komma igång; dokumentation på docs.docker.com/ai/docker-agent.

### munder-difflin — ett kontorslandskap för dina parallella kodningsagenter

**Vad det är:** En skrivbordsapp (Mac/Windows/Linux) som visar dina parallella AI-kodningsagenter som kollegor i ett gemensamt kontorslandskap — varje agent har sin inläda, ett Kanban-kort och ett långtidsminne.

**Varför det är intressant:** Att ha fem agenter i fem terminaler är lika kaotiskt som fem kollegor som skriker i var sin Zoom-ruta. munder-difflin ger en central vy: en "Michael"-orkestratör hanterar rutinbeslut automatiskt och eskalerar bara kritiska åtgärder till dig. Varje agent kör i egna git-arbetsytor (inga filkonflikter vid parallella skrivningar), och du kan sätta token-budgetar och schemalagda uppdrag. Jämfört med openrig är fokus på det visuella och på att minska beslutsbördan vid parallellt arbete.

**Buzz-nivå:** Håller på att bli en grej — ~6 500 GitHub-stjärnor, #5 Product of the Day på Product Hunt, tillagd i awesome-ai-agents-listan 5 oktober 2026.

**Testa:** https://github.com/HarnessMD/munder-difflin — ladda ner appen, konfigurera dina API-nycklar, kör din första mission.

### Photon — AI-agenter som lever i dina meddelandekanaler

**Vad det är:** Ett SDK och infrastrukturlager för att bygga AI-agenter som fungerar direkt i iMessage, WhatsApp, Telegram, SMS och e-post — utan att tvinga användarna att ladda ner en ny app.

**Varför det är intressant:** Det mest uppenbara hindret för att distribuera AI-agenter till vanliga användare är att ingen vill ha ännu en app. Photon löser det: agenten lever i de meddelandekanaler folk redan har, hanterar trådar och inloggning per kanal, och är plattformsnativ snarare än ett webbchat-fönster. 98 % av all användning är open source. Skiljer sig från Voiceflow och Botpress som kräver en webbläsare eller mobilapp.

**Buzz-nivå:** Håller på att bli en grej — stängde $4,5M seed-runda (Gradient, A*, Vercel m.fl.) den 2 oktober 2026, 40 000+ registrerade utvecklare, uppgiven 10x intäktstillväxt på fyra månader.

**Testa:** https://dealroom.co/news/158365-photon-raises-4-5m-to-build-agents-that-live-in-your-messaging-apps/ — sök photon-sdk på npm för att komma igång.

### zvec-grep — hitta vad du letar efter i koden, oavsett hur du söker

**Vad det är:** Ett sökverktyg (CLI + MCP-tillägg) från Alibabas Zvec-team som kombinerar exakt textsökning och semantisk "förstå-innebörden"-sökning i ett enda kommando.

**Varför det är intressant:** Agenter ställs ständigt inför ett val: söka exakt (hittar bara det de vet vad de letar efter) eller söka semantiskt (förstår innebörden men missar exakta matchningar). zvec-grep väljer metod automatiskt baserat på sökningen, indexerar hela kodbasen lokalt (inget lämnar maskinen) och kopplar som MCP-tillägg till Claude Code, Codex, Cursor och Qwen. Jämfört med Greptile och Sourcegraph Cody kräver det inget molnkonto och inga månadsavgifter.

**Buzz-nivå:** Börjar fångas upp — ca 3 100 stjärnor + 168 forks på GitHub, dök upp i GitHub Weekly MCP-trendlista veckorna 39–40 2026.

**Testa:** https://zvec.org/en/docs/zvec-grep/ — kör `zg index` i din projektkatalog, anslut som MCP-server i Claude Code.

### Dataiku Agent Management — äntligen en inventering av alla dina AI-agenter

**Vad det är:** En enterprise-produkt som automatiskt hittar och inventerar alla AI-agenter som körs i en organisation — oavsett om de byggdes i AWS Bedrock, Salesforce Agentforce, Copilot Studio, Snowflake eller Dataiku.

**Varför det är intressant:** "Agent sprawl" — för många agenter utan koll på vad de gör — är ett snabbt växande problem i organisationer. De flesta vet inte ens vilka agenter de kör, än mindre vilka som hanterar känslig kunddata. Dataiku täcker alla de stora plattformarna utan att kräva att agenterna byggs om, och rangordnar dem efter affärsrisk. Ingen annan känd produkt gör det cross-platform idag. IBM-forskning citerad i lanseringen: färre än var femte organisation har en komplett inventering av sina AI-system.

**Buzz-nivå:** Börjar fångas upp — lanserad 24 september 2026, GA planerad i oktober. Täckt av HelpNet Security och Technology Magazine.

**Testa:** https://www.dataiku.com/company/news/dataiku-agent-management-general-availability — produktsida med demo-förfrågan.

## Specialgrejer & experiment

### open-dots — din självhostade version av ChatGPT Agent

**Vad det är:** En MIT-licensierad, självhostad agent-arbetsyta som kör Claude Code-uppgifter i isolerade sandboxar med godkännandeflöden och resultatnotiser till Telegram.

**Varför det är intressant:** Positioneras som ett granskningsbart alternativ till ChatGPT Agent och Claude Cowork — du äger infrastrukturen, credentials krypteras i din egen databas, och varje riskabel åtgärd (filskrivning, git push) kräver ditt godkännande via webb-UI eller Telegram. Möjliggör schemalagda uppgifter med automatiska resultat till Telegram. Ännu en tidig prototyp men adresserar rätt problem för integritetsmedvetna team.

**Buzz-nivå:** Börjar fångas upp — 5 569 stjärnor, +464 senaste veckan; 28 commits (aktiv men tidig).

**Testa:** https://github.com/Anil-matcha/open-dots — `docker compose up` startar det lokalt.

---

### HarnessRouter — OpenRouter fast för agent-runtimes

**Vad det är:** Självhostat gateway (ett enda Docker-container) som exponerar ett gemensamt API framför Codex, Claude Code, Pi och DeepSeek Harness — du pratar med HarnessRouter och det väljer agent-runtime åt dig.

**Varför det är intressant:** Liknar vad OpenRouter gör för AI-modeller (en ingång, många modeller) men för agent-runtimes: en integration istället för en per agent. Om din organisation experimenterar med flera agenter slipper du underhålla separata kopplingar till varje en. Community Edition är Apache 2.0 och delar kodbas med molntjänsten (bara fakturering dolt). Uppges vara YC-backat.

**Buzz-nivå:** Börjar fångas upp — ~2 855 stjärnor i aggregatorkällor (oktober 2026), lanserat juli–september 2026.

**Testa:** https://github.com/HarnessRouter/harnessrouter — `docker compose up` startar det lokalt.
