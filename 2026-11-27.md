# AI-verktygs-spaning — 27 november 2026

## Inledning

Veckans spaning fångar ett tydligt mönster: infrastrukturen runt AI-agenter mognar snabbt. Det räcker inte längre att ha en agent — nu byggs verktygen som håller agenter säkra, koordinerade och ihågkommande. Tre YC-bolag i höstbatchens slutspurt fokuserar just på det. Dessutom: din inloggade webbläsare blir ett verktyg, och projekthanteringen ger AI-agenter riktiga platser i teamet.

## Gör Claude Code och andra AI-assistenter smartare

### Kaju — lägg kommentarer på Claude Codes terminalutdata med ett kortkommando

**Vad det är:** En liten macOS-app i menyraden som låter dig markera text direkt i Claude Code-terminalen, lägga till kommentarer och skicka alltihop tillbaka till sessionen med ett kortkommando — som att göra inline-kommentarer i ett dokument, men direkt i terminalen.

**Varför det är intressant:** Normalt copy-pastar man bitar ur Claude Code-output till ett nytt meddelande och förklarar vad man menar. Kaju låter dig annotera direkt på resultatet — och veriferar att Claude Code är i förgrunden innan den skriver i terminalen, vilket förhindrar oavsiktliga kommandon. Helt lokalt, ingen nätverksanslutning.

**Buzz-nivå:** Extremt tidigt. Lanserades 26 november 2026 (Show HN). v0.1.0, installeras via Homebrew.

**Testa:** https://github.com/aigeano/kaju — `brew install aigeano/tap/kaju`

### CLI Agent Orchestrator (AWS Labs) — låt Claude Code och Codex jobba parallellt på samma uppgift

**Vad det är:** Verktyg från AWS Labs som koordinerar Claude Code, Codex CLI, Kiro CLI och GitHub Copilot CLI i parallella isolerade sessioner med en supervisor-agent som delar upp ett problem och skickar deluppgifter till de bäst lämpade verktygen.

**Varför det är intressant:** Att manuellt växla mellan flera AI-coding-verktyg är tidsödande. Det här gör det automatiskt — som att ha en projektledare för dina AI-assistenter. Tidigt stadium men Apache 2.0-licensierat och från AWS Labs, vilket ger det trovärdighet som infrastrukturverktyg.

**Buzz-nivå:** Börjar fångas upp. 1 698 stjärnor på GitHub (november 2026).

**Testa:** https://github.com/awslabs/cli-agent-orchestrator

### Supermemory — ett delat minne för Claude Code, Cursor och Codex

**Vad det är:** Open source-minneslager där Claude Code, Cursor och Codex delar ett och samma dynamiskt minne kopplat till ditt Git-repo — agenten minns vad som diskuterades förra veckan, oavsett vilket verktyg du öppnade då.

**Varför det är intressant:** CLAUDE.md och Cursor Rules är statiska textfiler — Supermemory är ett lager som agenter kan läsa och skriva under körning. Separata plugins för varje kodningsagent lanserades sent november 2026 (repos: `claude-supermemory`, `cursor-supermemory`, `codex-supermemory`). Kör helt lokalt med ett enda kommando.

**Buzz-nivå:** Börjar fångas upp. Aktiv GitHub-organisation med plugin-lansering och changelog november 2026.

**Testa:** https://github.com/supermemoryai/supermemory — kör `npx supermemory local` för lokal drift

### OpenCrawl — delad sessionhistorik för agenter som jobbar på samma sak

**Vad det är:** Kontextlager (YC Fall 2026) som låter Claude Code, Codex och andra MCP-klienter söka i varandras sessionhistorik — agenten ser vad kollegans agent redan testade, oavsett maskin.

**Varför det är intressant:** Agenter på olika maskiner eller i CI-pipelines vet normalt ingenting om varandra. OpenCrawl löser det: varje agentkörning bidrar till ett delat sökbart minne som nästa agent kan slå upp. Självhostat, Apache 2.0.

**Buzz-nivå:** Extremt tidigt. YC Fall 2026-bolag, lanserades 24 november 2026.

## Verktyg, automation & infrastruktur

### Browser MCP — din AI-agent använder din redan inloggade webbläsare

**Vad det är:** Chrome-extension kombinerad med MCP-server som låter AI-agenten styra din befintliga, inloggade Chrome-session — agenten ser och klickar i de sidor du redan är inloggad på, med dina cookies och sessioner intakta.

**Varför det är intressant:** De flesta webbläsarautomatiseringsverktyg startar en tom ny webbläsare utan dina inloggningar. Browser MCP är tvärtom: agenten agerar med din befintliga session. Credentials delas aldrig med agentkoden — kommunikation sker via Chrome DevTools Protocol via extensionen. Fungerar med Claude Code, Cursor, Codex och Claude Desktop. Engångsgodkännande per dator via en sexsiffrig kod.

**Buzz-nivå:** Håller på att bli en grej. 7 400 stjärnor på GitHub (november 2026). Listad i MCP-kataloger och "Best Browser Agent MCP Servers 2026".

**Testa:** https://github.com/BrowserMCP/mcp — installera Chrome-extensionen och konfigurera som MCP-server i ditt AI-verktyg

### boxes.dev — molndatorer dedikerade för dina AI-kodningsagenter

**Vad det är:** Molntjänst (YC Fall 2026) som ger varje AI-kodningsagent en egen persistent VM med din devmiljö — agenten fortsätter arbeta i bakgrunden även när du stänger laptoppen, och du återansluter till exakt det tillstånd den lämnade.

**Varför det är intressant:** "Agent dör när du lägger ner locket" är ett välkänt irritationsmoment. boxes.dev löser det utan att du behöver hantera egna cloud-instanser. Säljer inga tokens — du använder din befintliga Claude Code- eller Codex-prenumeration. Gitpod och devcontainers riktar sig till människor, inte agenter.

**Buzz-nivå:** Extremt tidigt. YC Fall 2026-bolag, lanserades 24 november 2026, 3 gratismånader Pro som promo.

**Testa:** https://boxes.dev — skapa ett konto och länka din befintliga Claude Code-installation

### Agent Substrate — trygg runtime för att köra tusentals agenter säkert

**Vad det är:** CNCF Sandbox-projekt (Go, v1.0) som ger en zero-trust körmiljö för AI-agenter på Kubernetes — varje agent körs isolerad i sin egen sandlåda och känsliga uppgifter hanteras aldrig direkt inuti agentkoden.

**Varför det är intressant:** Att driftsätta agenter i produktion säkert är löst på pappret men svårt i praktiken. Agent Substrate ger inaktiva agenter en "frysningsfunktion" (snapshots) som startar snabbt igen, och ett gateway-lager utanför agenten hanterar alla externa credentials. CNCF-stämpeln på v1.0 ger det tyngd som infrastrukturstandard.

**Buzz-nivå:** Håller på att bli en grej. 8 450 stjärnor, +656 stjärnor senaste veckan (Go weekly trending, november 2026).

**Testa:** https://github.com/agent-substrate/substrate

### Clam — ge din agent tillgång till inkorgen, men på dina villkor

**Vad det är:** Hostad MCP-server som ger AI-agenter regelbaserad tillgång till din e-postinkorg — utan att agenten någonsin får ditt lösenord. Allt utanför de explicit tillåtna åtgärderna är blockerat som standard, och känsliga förfrågningar köas för manuellt godkännande.

**Varför det är intressant:** Att ge en agent tillgång till Gmail eller Outlook är vanligtvis ett allt-eller-inget-beslut. Clam är ett kontrollager: du bestämmer exakt vad agenten får göra med din inkorg. Listad på Claude Marketplace.

**Buzz-nivå:** Extremt tidigt. Omnämnd i agent-nyhetsbrev november 2026, listad på mcpservers.org.

**Testa:** https://mcpservers.org/servers/useclam-ai-docs

## Specialgrejer & experiment

### Atomic Agents (Eigenwise) — byggsatsen för förutsägbara agentpipelines

**Vad det är:** Lättviktig, öppen Python-ramverk (MIT) för AI-agentpipelines med sammansättningsbara komponenter, explicit schema-validering och inbyggd observabilitet — tänk Lego-klossar för agenter snarare än en stor magisk låda.

**Varför det är intressant:** LangChain och LlamaIndex är mäktiga men notoriskt svårdebuggade vid produktionsdrift. Atomic Agents satsar på small-and-composable: varje agent har ett definierat input/output-schema, flödet kontrolleras av vanlig Python (inga dolda orchestration-loopar), och varje tool-anrop ger ett mätpunkt för loggning. Version 2.0 inkluderar agent-skills så att coding-assistenter kan lära sig API:et live. Fungerar med Claude, OpenAI, Groq, Gemini och Ollama.

**Buzz-nivå:** Håller på att bli en grej. 6 300 stjärnor, 1 249 commits, v2.0 (AI-radar 25 november 2026).

**Testa:** https://github.com/Eigenwise/atomic-agents — `pip install atomic-agents`
