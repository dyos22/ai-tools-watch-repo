# AI-verktyg att hålla koll på — 7 september 2026

## Inledning

Den här veckan domineras av ett infrastrukturellt skifte: de stora aktörerna — Vercel, OpenAI, Anthropic, GitHub och Microsoft — har enats om ett gemensamt format för agentskills, analogt med hur npm standardiserade pakethantering för JavaScript. Det signalerar att ekosystemet lämnar prototypfasen och börjar organisera sig på allvar. Parallellt syns en rörelse mot nollfriktions-tillgänglighet: en webbläsarbaserad MCP-studio utan installationskrav, en sökmotor för agenter utan API-nycklar, och ett minnessystem som retroaktivt indexerar allt som redan finns på din disk. Kostnadskontroll är det tredje temat — ett nytt öppet benchmark visar var kodningsagenter faktiskt presterar, och en YC-agent hävdar 27 % lägre kostnad än Claude Code med konkreta mätetal.

## Gör Claude Code och andra AI-assistenter smartare

### Bullet (YC S26)

**Vad det är:** En snabbare, billigare kodningsagent som installeras som ett CLI-program och fungerar som drop-in-ersättare för Claude Code och Codex.

**Varför det är intressant:** Claude Code och Codex hanterar uppgifter sekventiellt — en sak i taget. Bullet paralleliserar underuppgifter, hanterar kontext smartare och levererar enligt egna mätningar 95,8 % lösningsgrad på SWE-bench Verified (topp 3 globalt), 27 % lägre kostnad och 16 % färre rundturer mot modellen jämfört med Claude Code. Byggt av Yale CS-grundare med bakgrund från AppLovin och Citadel; YC-finansierat (S26-batchen).

**Buzz-nivå:** Håller på att bli en grej — YC S26-lansering med Launch HN-diskussion på Hacker News; konkreta benchmarksiffror mot Claude Code publicerade.

**Testa:** https://www.codewithbullet.com — installera via `npm install -g @trybullet/cli`.

### deja-vu

**Vad det är:** En liten binärfil som ger dina kodningsagenter (Claude Code, Codex, Cursor) sökbart minne — utan molntjänst, utan extra konfiguration, utan att agenten ens behöver veta om det.

**Varför det är intressant:** De flesta minneslösningar för agenter (som Agentmemory, täckt i tidigare rapport) kräver ett eget insamlingssteg och i regel en molnbackend. deja-vu gör ingenting av det: den läser de sessionsloggar som Claude Code och Cursor *redan* sparar på din disk och bygger retroaktivt ett sökbart index — månader av historik indexeras på 7–9 millisekunder. Injicera sedan relevant historik automatiskt när nästa session startar. MIT-licens, noll cloud-beroende, fungerar bakåt i tiden utan att du behövt installera det förut.

**Buzz-nivå:** Extremt tidigt — 222 GitHub-stjärnor, nämnt i LLM Daily 3–4 september 2026.

**Testa:** https://github.com/vshulcz/deja-vu — installera binären och peka den mot din sessions-katalog; README visar konfigurationen för Claude Code.

### hf CLI (HuggingFace — agent-optimerat läge)

**Vad det är:** HuggingFace-klientens kommandoradsverktyg har fått ett "agent-läge" som automatiskt detekterar om det är en AI-agent som kör kommandot — och i så fall skickar strukturerad, komprimerad utdata i stället för den färgglada människovänliga versionen.

**Varför det är intressant:** Nästan alla kommandoradsverktyg är designade för mänskliga ögon — de innehåller färgkoder, animationer och förkortad information som är meningslös för en AI-agent och äter upp dyrbart utrymme i konversationshistoriken. hf CLI är ett av de första praktiska exemplen på ett "agent-native CLI": upp till 6× lägre token-förbrukning på komplexa flerstegsuppgifter jämfört med att agenten kör vanliga nätverksanrop mot API:et direkt. HuggingFace rapporterar 40 000 Claude Code-användare och 49 miljoner anrop mot HF-infrastruktur i juli 2026. Mönstret förväntas spridas till andra CLI-verktyg.

**Buzz-nivå:** Börjar fångas upp — officiell bloggpost från HuggingFace med konkreta effektivitetssiffror; agent-trafiktillägg aktivt sedan april 2026.

**Testa:** https://huggingface.co/blog/hf-cli-for-agents — uppdatera `huggingface_hub`-paketet till senaste versionen; agent-läget aktiveras automatiskt.

### Agent MCP Studio

**Vad det är:** En webbläsarbaserad studio för att bygga och testa MCP-system (de kopplingar som ger AI-agenter tillgång till externa verktyg och tjänster) — direkt i webbläsarfliken, utan server, Docker eller installation.

**Varför det är intressant:** Att sätta upp och testa ett MCP-system kräver normalt en lokal Python-miljö, Docker och manuell konfiguration. Agent MCP Studio kör allt i webbläsaren: koden kompileras direkt i fönstret, databasfrågor körs lokalt, och AI-modellen kan köras på din dator utan att data lämnar den. Tio inbyggda strategier för att koordinera flera agenter. Stäng fliken och allt är borta — inget sparas i molnet. Perfekt för att prototypa och testa innan man driftsätter på riktigt.

**Buzz-nivå:** Börjar fångas upp — Show HN 5 maj 2026 med engagerad diskussion på Hacker News.

**Testa:** https://news.ycombinator.com/item?id=47899375 — länk till studion i HN-tråden.

## Verktyg, automation & infrastruktur

### Agent Plugins (Vercel, OpenAI, Anthropic, Microsoft, AWS m.fl.)

**Vad det är:** Ett nytt gemensamt paketformat — likt npm-paket men för AI-agentskills — som gör att en skill du bygger eller installerar fungerar i ChatGPT, Claude, Cursor, GitHub Copilot, VS Code och Windsurf utan ändringar.

**Varför det är intressant:** MCP-protokollet löste "hur agenter pratar med verktyg", men varje klient hade fortfarande egna format för att paketera och distribuera dessa verktyg. Agent Plugins är nästa lager: en installationsenhet som bär med sig både logiken och serveruppsättningen. Analogin är npm för Node.js — en gång etablerats sprider sig ekosystemet snabbt. Det ovanliga är bredden av aktörer vid GA-lansering: Vercel, OpenAI, Anthropic, AWS, GitHub och Microsoft stod tillsammans bakom version 1.0.0, med Google som core-maintainer dagen efter.

**Buzz-nivå:** Håller på att bli en grej — GA-lansering 6 augusti 2026, stödd av alla större aktörer i agentutvecklings-ekosystemet; specifikation och authoring-guides live på agent-plugins.org.

**Testa:** https://vercel.com/blog/introducing-agent-plugins — specifikation och author-guides på agent-plugins.org.

### ACI.dev

**Vad det är:** En öppen plattform som kopplar AI-agenter till 600+ tjänster (Google Calendar, Slack, GitHub, databaser m.m.) via ett enda standardiserat lager — självhostbar, utan obligatorisk molntjänst.

**Varför det är intressant:** Composio och Zapier MCP löser samma problem men kräver molnkonton och delar data med tredjepart. ACI är MIT-licensierat, kör på dina egna servrar, och hanterar OAuth-inloggning och behörigheter per agent — inte per användare. Det innebär att du kan ge en agent åtkomst till din kalender utan att ge den åtkomst till din e-post. Projektet beskriver sig som "födelseplatsen för VibeOps" — ett mönster där agenter driver automatiseringsflöden i stället för mänskliga administratörer.

**Buzz-nivå:** Börjar fångas upp — nämnt i Ben's Bites och kurerade "best of agent infrastructure"-listor maj–september 2026.

**Testa:** https://github.com/aipotheosis-labs/aci — installera via README; stöder Claude Code och alla MCP-kompatibla klienter.

### wigolo

**Vad det är:** En lokal sökmotor och webb-crawlare som ger AI-agenter gratis, privat webbsökning — utan API-nycklar och utan kostnad per förfrågan.

**Varför det är intressant:** Tavily, Exa och Brave Search API är de vanligaste sätten att ge agenter söktillgång — alla kräver ett konto och kostar per förfrågan. wigolo körs lokalt, lagrar cachad historik under din hemmapp och kombinerar resultat från flera sökmotorer med lokal ML-rangordning. Anslut via MCP-protokollet till Claude Code, Cursor eller VSCode. Noll kostnad per sökning, allt stannar på din maskin.

**Buzz-nivå:** Håller på att bli en grej — 5 100 GitHub-stjärnor (TypeScript), +362 stjärnor den senaste veckan.

**Testa:** https://github.com/KnockOutEZ/wigolo — installera och koppla Claude Code mot den lokala MCP-servern via konfigurationsfilen.

### Agentled

**Vad det är:** En MCP-server med inbyggt minne och arbetsflödeshantering — agenter kan starta, pausa och återuppta flerstegsjobb som sträcker sig över flera sessioner.

**Varför det är intressant:** De flesta MCP-servrar är stateless: agenten anropar ett verktyg, får ett svar, och nästa session vet ingenting om det förra anropet. Agentled bryter det mönstret — agenten kan minnas vad den gjorde förra veckan och fortsätta ett arbetsflöde där det slutade, med 100+ inbyggda integrationer och en enda API-nyckel. Direkt konkurrent till n8n och Make.com, men designat för att drivas av agenter i stället för av människor via ett grafiskt gränssnitt. Distribueras som ett Agent Plugins-paket.

**Buzz-nivå:** Börjar fångas upp — nämnt i kurerade listor september 2026.

**Testa:** https://github.com/agentled/mcp-server — lägg till som MCP-server i Claude Code-konfigurationen.

### AI Manifest (IETF-draft)

**Vad det är:** Ett JSON-format som webbplatser bäddar in för att deklarera hur AI-agenter ska navigera dem — klickbara element, formulärsteg, transaktionsflöden — i stället för att agenten ska gissa sig fram i webbsidans källkod.

**Varför det är intressant:** Webb-agenter analyserar idag hela webbsidans källkod om och om igen för varje steg — dyrt och opålitligt. AI Manifest är som "ett brev till agenten" inbäddat av webbplatsen: "knappen du letar efter finns här, formuläret följer dessa steg". Referensimplementeringen visade 81,9 % minskning i tokenanvändning och uppgiftssuccé som steg från 20 % till 100 %. Nu ett officiellt IETF-utkast — en standardiseringsprocess med potential att förändra hur alla webb-agenter fungerar.

**Buzz-nivå:** Börjar fångas upp — IETF-draft publicerat 15 maj 2026 (draft-han-ai-manifest-01), standardiseringsprocess pågår.

**Testa:** https://datatracker.ietf.org/doc/draft-han-ai-manifest/01/ — läs specifikationen; implementering på egna webbplatser kan börja redan nu.

## Specialgrejer & experiment

### Soup

**Vad det är:** Ett verktyg som låter dig specialträna (finjustera) en AI-modell på ditt eget material med en enda YAML-konfigurationsfil — och som kör på grafikkort med bara 4 GB minne.

**Varför det är intressant:** Att träna en AI-modell på ditt eget material (dina dokument, din kodbas, din kundtjänsthistorik) kräver normalt tunga servrar och djup teknisk kompetens. Soup använder en ny teknik kallad "layer streaming" — modellen laddas in ett lager i taget i stället för allt på en gång — vilket gör det möjligt på ett vanligt konsumentkort med 4 GB grafikkortsminnne. En fil och ett kommando: `soup train config.yaml`. Uppmätt prestanda: 119,6 tokens per sekund med 3,32 GB minnesanvändning på ett RTX 3050-kort. Teknik beskrivs i en peer-reviewed preprint.

**Buzz-nivå:** Håller på att bli en grej — 5 200 GitHub-stjärnor, +1 900 på 8 dagar, rankas #1 i snabbast stigande lokal-AI-repon (september 2026, findarepo.com).

**Testa:** https://github.com/MakazhanAlpamys/Soup — en YAML-fil och `soup train config.yaml`; README visar ett komplett träningsexempel.

### DeepSWE

**Vad det är:** Ett öppet benchmark-dataset med 113 originella programmeringsuppgifter hämtade ur aktiva open source-projekt — för att mäta hur bra AI-kodningsagenter egentligen presterar på riktiga, komplexa uppgifter.

**Varför det är intressant:** SWE-bench är det dominerande sättet att jämföra kodningsagenter idag, men dessa uppgifter är välkända i träningsdatan — en agent kan i princip ha "memorerat" svaren. DeepSWE använder uppgifter från projekt som inte ingår i standardträningsdata, täcker fem programmeringsspråk (TypeScript, Go, Python, JavaScript, Rust) och kör agentens kod i isolerade miljöer för reproducerbara jämförelser. Nyttigt att hålla koll på nästa gång en leverantör publicerar prestationsanspråk.

**Buzz-nivå:** Börjar fångas upp — arXiv-preprint (2607.07946), GitHub trending-lista 4 september 2026.

**Testa:** https://github.com/datacurve-ai/deep-swe — kör din agent mot datasetet eller läs ledartavlan på deepswe.datacurve.ai.

### feynman

**Vad det är:** En terminalklient för akademisk litteraturgenomgång med fyra koordinerade underagenter (Researcher, Reviewer, Writer, Verifier) som söker, granskar och verifierar citat mot källan.

**Varför det är intressant:** ChatGPT Deep Research kan inte söka direkt i PubMed, UniProt eller AlphaXiv, och citerar ibland fel. feynman kopplar direkt till dessa databaser och låter en dedikerad Verifier-agent kontrollera varje påstående mot källtexten — inga hallucinerade referenser. Fungerar helt offline med lokala modeller via Ollama. Mer nischat (vetenskap och akademi), men mönstret med rollspecialiserade agenter i en verifieringskedja är intressant och spridningsbart.

**Buzz-nivå:** Börjar fångas upp — 8 900 GitHub-stjärnor (Python).

**Testa:** https://github.com/advaitpaliwal/feynman — installera och konfigurera kopplingen mot önskat modell-API; stöder Ollama för helt lokal körning.
