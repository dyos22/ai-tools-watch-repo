# AI-verktygs-spaning — 23 november 2026

## Inledning

Veckans spaning har ett tydligt underliggande tema: *åtkomst och tillit*. Nu när AI-agenter rutinmässigt används i produktion — de skriver kod, hanterar dataflöden, kontaktar externa tjänster — uppstår strukturella frågor om vem de egentligen är, vad de faktiskt får göra, och hur de koordinerar med varandra. Den här veckan svarar fyra separata projekt på de frågorna: ett standardprotokoll för hur personliga agenter autentiseras mot företagstjänster (PAP), ett proxylager för MCP-credentials (LangSmith Tool Gateway), ett finkornigt åtkomstkontrollager för GitHub (GitRails), och ett asynkront koordinationslager för agentteam (Vercel Board). Parallellt: Replit visar att svärmar av 32 parallella agenter är produktionsfärdiga, och Databricks' ZeroOps-agent stänger loopen för DataOps helt autonomt. Elva verktyg totalt.

## Gör Claude Code och andra AI-assistenter smartare

### LangSmith Tool Gateway — en nyckelring för alla MCP-verktyg

**Vad det är:** En managed proxy-tjänst från LangChain som sitter framför alla dina MCP-servrar och hanterar API-nycklar, åtkomstpolicyer och granskningsloggar från ett enda ställe.

**Varför det är intressant:** Idag har en typisk Claude Code-installation ett dussintal separata MCP-servrar — Slack, GitHub, Jira, databaser — var och en med egna nycklar klistrade i konfigurationsfiler. LangSmith Tool Gateway ersätter det med en enda URL. Du berättar vem som får använda vilka verktyg (en specifik agent, en profil, hela workspacen), och gatewayen loggar varje anrop med vem som kallade vad och när. Jämfört med att köra MCP-servrar direkt ger Gateway ett kontrollager som är avgörande när agenter börjar agera i produktion med verkliga konsekvenser. Stöder GitHub, Slack, Salesforce, Linear och fler via inbyggda servrar.

**Buzz-nivå:** Håller på att bli en grej — public beta lanserades 19 november 2026 på LangSmith Plus och Enterprise. Omnämnt oberoende av Agent 1 (GitHub Trending-aggregatorer) och Agent 2 (Reddit-communityt) i samma körning — tydlig signal.

**Testa:** https://langchain.com/blog/langsmith-tool-gateway — kräver LangSmith-konto (Plus eller Enterprise).

### GitRails — ge agenten exakt rätt GitHub-åtkomst, inte mer

**Vad det är:** En proxy som sitter framför GitHub REST API och låter dig skapa API-nycklar som begränsar agenter till exakt de endpoints, repos och URL-mönster du anger.

**Varför det är intressant:** GitHubs inbyggda OAuth-behörigheter är för grova för agenter: "read:repo" ger läsrättigheter till *alla* repos, inte bara det relevanta. GitRails löser det med ett extra filtreringslager: ge en kodningsagent write-access till exakt ett testförråd men bara read-access till ett annat, utan att ändra ett enda anrop i agentens kod. Verktyget fick extra uppmärksamhet efter "GitLost-incidenten" sommaren 2026, då en agent läckte privat kod via prompt injection — GitRails hade blockerat det attackmönstret strukturellt. Jämfört med Bay AI (täckt 15 november 2026, som blockerar riskfyllda handlingar i realtid) är GitRails ett strukturellt förebyggande lager, inte en vakthund.

**Buzz-nivå:** Börjar fångas upp — lanserades april 2026, Show HN; 21 endpoints stöds; aktiv GitHub App under `github.com/apps/gitrails-ai`.

**Testa:** https://github.com/apps/gitrails-ai

Jämfört med Jan (UI-fokuserat men smalare) är LocalAI djupare integrerat med plugins och Office-verktyg; jämfört med LM Studio har det ett mer öppet plugin-ekosystem.

**Buzz-nivå:** Håller på att bli en grej — v5.0.0 lanserades 18 november, v5.0.1 20 november 2026. ## Verktyg, automation & infrastruktur

### Replit Missions — ett koordinerat agentteam tar sig an hela uppdraget

**Vad det är:** Replits produktionsfärdiga multi-agent-svärmsystem där du sätter ett mål, en kostnadsgräns och godkännandekriterier — en svärm av upp till 32 parallella agenter planerar, bygger och itererar tills en fristående verifieringsagent godkänner resultatet.

**Varför det är intressant:** De flesta AI-kodningsverktyg — Claude Code, Cursor, Codex — är enkla agenter: en konversation, ett problem i taget. Replit Missions koordinerar ett helt team: en "Lead"-agent delar upp arbetet, worker-agenter utför parallellt, och en separat "Review"-agent kontrollerar resultatet mot dina kriterier utan mänsklig inblandning. Replit använde verktyget för att bygga sin egen produktionsmonitoringplattform Radar. Egna mätningar rapporterar 17–19× snabbare genomförande med 32 agenter jämfört med ett enda bygge (ej oberoende verifierade). Kostnadsgränsen är central: du sätter ett maxtak och Missions stoppar när det är nått.

**Buzz-nivå:** Håller på att bli en grej — lanserades 17 november 2026. Rapporterat av The New Stack, ByteIota och FourWeekMBA. Omnämnt oberoende av Agent 1 (HN/GitHub/Product Hunt) och Agent 2 (Reddit) i samma körning.

**Testa:** https://replit.com/blog/introducing-replit-missions — kräver Replit-konto.

### Vercel Board — asynkront koordinationslager för agentteam

**Vad det är:** Vercels experimentella "headless Slack for agents" — en delad meddelandebräda där en lead-agent planerar arbete och worker-agenter tävlar om och slutför enskilda uppgifter med beroendespårning, asynkront.

**Varför det är intressant:** De flesta multi-agent-system förutsätter synkron kommunikation: Agent A väntar på svar från Agent B. Vercel Board är asynkront — agenter tar uppgifter, utför dem och rapporterar tillbaka i sin egen takt, koordinerade via en gemensam board. Det löser problemet med agenter som kör i heterogena miljöer (olika sandlådor, molntjänster, tidszoner) och behöver synkronisera utan direkt nätverk mot varandra. Per-channel åtkomstkontroll styr vem som läser vad. Synkroniseras med Slack och GitHub via CLI (`vercel board`) och SDK (`@vercel/board`). Jämfört med Replit Missions (ovan, som är en heltäckande agentsvärm-plattform) är Board ett lättviktigt kommunikationsprimitiv du lägger till din befintliga agentarkitektur.

**Buzz-nivå:** Börjar fångas upp — lanserades 18 november 2026 i Vercels changelog. Labellerat experimentellt. Tillgängligt på alla Vercel-planer.

**Testa:** https://vercel.com/changelog/vercel-board-is-now-available

### Personal Agent Protocol (PAP) — standarden för hur din agent shoppar och betalar åt dig

**Vad det är:** En öppen standard från Sierra och Meta som definierar hur en personlig AI-agent autentiseras mot och interagerar med externa företagstjänster — shopping, betalningar, support — utan att du behöver lämna ifrån dig lösenord.

**Varför det är intressant:** MCP hanterar hur AI-modeller pratar med verktyg. A2A hanterar hur agenter pratar med agenter. PAP fyller det tredje gapet: hur din personliga agent autentiseras och kommunicerar med externa företagstjänster — som att låta agenten köpa något på Shopify eller öppna ett supportärende hos Genesys, med ett åtkomstkontrollager som *du* äger, inte företaget. Shopify, Stripe, Walmart och Genesys är redan ombord. Jämfört med att agenten använder ditt befintliga inlogg direkt (farligt, inget spår) ger PAP ett delegerat, begränsat och spårbart åtkomstsystem.

**Buzz-nivå:** Håller på att bli en grej — 35+ nya partners under oktober–november 2026. Täckt av TechZine, SingleGrain, YouStory och Decagon. Sierra grundades av ex-Salesforce CEO Bret Taylor och är välfinansierat.

**Testa:** https://sierra.ai/uk/blog/introducing-personal-agent-protocol

### Databricks Genie ZeroOps — datainfrastrukturens vakt som aldrig sover

**Vad det är:** En autonom DataOps-agent (öppen beta) som kontinuerligt övervakar Databricks datapipelines och jobb, diagnostiserar fel med hjälp av Unity Catalog-metadata och öppnar PRs med konkreta kodkorrigeringar för mänskligt godkännande.

**Varför det är intressant:** Traditionell monitoring larmar: "jobb XX misslyckades kl. 03:45". Du vaknar, tittar, debuggar och fixar manuellt. ZeroOps stänger hela den loopen: agenten identifierar rotorsaken, skriver det faktiska fixet, och öppnar en PR med rotorsaksbeskrivningen bifogad — du behöver bara granska och godkänna. Tränad på 80 000 verkliga kundfelsfall. Drivs av Anthropic-modeller som körs *inom* Databricks säkerhetsperimeter — datan lämnar aldrig plattformen. Jämfört med allmänna agentverktyg (en Claude Code-session du startar manuellt) är ZeroOps pre-tränat för Databricks-specifika incidentmönster och kör autonomt dygnet runt.

**Buzz-nivå:** Håller på att bli en grej — public beta lanserades 19 november 2026 (Databricks-blogg, Unite.AI, Pulse2.com). Omnämnt oberoende av Agent 1 och Agent 2 i samma körning.

**Testa:** https://www.databricks.com/blog/introducing-genie-zeroops — aktiveras via Previews-sidan i Databricks-workspace.

### Exa Websets V2 — bygg ett strukturerat dataset från live-webben, rad för rad

**Vad det är:** En webb-datainfrastruktur-API som bygger verifierade, anpassade dataset från live-webben — V2 är 4× snabbare och hälften så dyrt som V1, från Exa ($250M Series C, maj 2026).

**Varför det är intressant:** De flesta sökmotorer för agenter returnerar URL:er och textutdrag. Websets returnerar *strukturerade rader* — varje rad är ett verifierat webbobjekt (ett företag, en person, en artikel) med berikade kolumner du anger. En agent som ska bygga en lista av alla startup-grundare inom ett specifikt område kan hämta ett strukturerat dataset direkt via API, utan att skrapa och parsa manuellt. V2:s förbättringar gör det tillräckligt billigt för produktion-agentloops: $0,017–$0,024 per verifierad rad (interna benchmarks). Jämfört med standard websökning (Brave API, Tavily) är Websets mer strukturerat och verifierat; jämfört med att scrapa manuellt är det ordrar av magnitude snabbare.

**Buzz-nivå:** Håller på att bli en grej — nyligen lanserad V2, 143 upvotes på Product Hunt.

**Testa:** https://exa.ai/websets — `pip install exa-py` för SDK-åtkomst.

### AlterContacts — CRM-agenten som proaktivt bevakar dina klientrelationer

**Vad det är:** En AI-agent som kopplas till ditt CRM och proaktivt övervakar alla klientrelationer — flaggar at-risk-konton, påminner om uppföljningar och skriver utkast till outreach *innan* du behöver fråga.

**Varför det är intressant:** De flesta CRM-system (Salesforce, HubSpot) är passiva databaser: de gör ingenting tills du frågar. ## Specialgrejer & experiment

### LibreAGI — P2P-nätverket som betalar dig för att dela öppna modeller

**Vad det är:** Ett P2P-distributionsnätverk för öppna AI-modellvikter med ett incitamentssystem — seeders med sällsynta filer betalar upp till 4× standardersättning för att göra dem tillgängliga.

**Varför det är intressant:** Öppna modeller på HuggingFace försvinner ibland när kostnaden för att hosta dem överstiger vad skaparen har råd med — ett strukturellt hållbarhetsproblem. LibreAGI löser det med en BitTorrent-liknande ekonomi: de som håller filerna tillgängliga kompenseras, med högre betalning för sällsynta filer. Nätverket accepterar bara modeller med godkända licenser (Apache-2.0, MIT, Qwen Community License), verifierade mot källkod och granskade manuellt. Jämfört med HuggingFace ger LibreAGI finansiella incitament till distributörer — ett nytt sätt att lösa hållbarhetsfrågan för öppna modeller.

**Buzz-nivå:** Extremt tidigt — omnämnt i Zeli-aggregator november 2026.

**Testa:** https://zeli.app/story/50467439

### Google Mirror Dimension — Googles testlabb för att knäcka webbläsaragenter *(ej publik ännu)*

**Vad det är:** Googles Chrome Security-teams hermetiska sandboxmiljö för att köra 1 000+ adversariella testscenarier per dag mot AI-webbläsaragenter — syntetiska banker, butiker och sociala medier som aktivt försöker lura agenterna.

**Varför det är intressant:** Browser-agenter som använder webben är sårbara för prompt injection-attacker — skadlig text på en webbsida som försöker manipulera agenten att göra något annat. Mirror Dimension är en systematisk testmiljö: varje körning startar från identiskt rent läge, attackpayloads levereras via en dold HTTP-header så agenten inte ser det som ett uppenbart test, och varje session körs i isolerade sandlådor. Det är ett tidsdokument — att Google formaliserar adversariell testning för agenter i den här skalan signalerar att prompt injection mot webbläsaragenter är ett problem som tas på allvar i produktion.

**Buzz-nivå:** Börjar fångas upp — publicerades 19 november 2026 (Chrome Security Blog, WIRED, AIWeekly). Internt verktyg; ingen publik release ännu.

**Testa:** Ej publik ännu — https://blog.google/security/mirror-dimension-for-agents/ (bloggpost)
