# AI-verktyg att hålla koll på — 3 september 2026

## Inledning

Veckan kring 3 september syns en tydlig mognadsröst i AI-verktygslådan: vi har gått från att fråga "kan agenter göra X?" till att faktiskt mäta hur bra de klarar det — och svaret är nedslående nyktra. Tre separata benchmark-projekt visar att agenter som påstår sig prestera i toppklass på standardtest rasar till en bråkdel av den nivån när de möter riktiga sajter och riktiga arbetsflöden. Samtidigt landar verktyg som gör det enklare att sätta upp sin egen agent-miljö, förstå vad agenten egentligen gör, och styra den hela vägen ner till mobilskärmen.

## Gör Claude Code och andra AI-assistenter smartare

### Chrome DevTools MCP (Google Chrome-teamet)

**Vad det är:** Googles Chrome-team har publicerat en officiell integration som ger Claude Code och Cursor direkt tillgång till 44 inbyggda webbläsarverktyg — de verktyg webbutvecklare normalt öppnar Chrome DevTools för att använda.

**Varför intressant:** Normalt kan Claude Code bara titta på kod — inte se vad som faktiskt händer när en webbsida körs live. Med Chrome DevTools MCP kan agenten ta skärmdumpar, se vilka nätverksförfrågningar som görs, hitta var ett fel uppstod i den körda koden, och analysera hur snabb en sida faktiskt är — allt inifrån Claude Code, utan att du öppnar Chrome manuellt. Det är som att ge agenten glasögon för att se webb-applikationer i rörelse, inte bara som statisk text. Att det är officiellt från Chrome-teamet betyder att integrationen håller jämna steg med webbläsarens uppdateringar.

**Buzz-nivå:** Håller på att bli en grej — officiellt underhållen av Chrome-teamet, 48 releaser, +849 GitHub-stjärnor den senaste veckan (september 2026).

**Testa:** https://github.com/ChromeDevTools/chrome-devtools-mcp — lägg till som MCP-server i Claude Code-konfigurationen.

### GitNexus (abhigyanpatwari)

**Vad det är:** Ett verktyg som analyserar ett helt kodprojekt och bygger en karta över hur alla delar hänger ihop — filerna, funktionerna och deras beroenden — och gör den kartan tillgänglig för Claude Code och Cursor via MCP.

**Varför intressant:** När ett projekt växer sig stort kan Claude Code inte längre läsa allt på en gång — den ser bara de filer du öppnar just nu. GitNexus ger agenten en permanent fågelperspektivskarta av hela projektet: modul A anropar modul B, som beror på C. Agenten kan hoppa direkt till rätt del utan att leta. Verktyget kör helt i webbläsaren utan en extern server — ingen molntjänst ser din kod.

**Buzz-nivå:** Börjar fångas upp — nyligen lanserat, uppmärksammat på Hacker News (september 2026).

**Testa:** https://github.com/abhigyanpatwari/GitNexus — installera och konfigurera som MCP-server i din editor.

## Verktyg, automation & infrastruktur

### Open Multi-Agent (open-multi-agent)

**Vad det är:** Ett ramverk som låter dig starta ett team av AI-agenter med ett enda mål på vanlig text — systemet planerar och fördelar arbetet dynamiskt, utan att du behöver rita upp hur de ska samarbeta.

**Varför intressant:** Att bygga multi-agent-system med de flesta ramverken (som LangGraph) kräver att du manuellt definierar varje agent och i vilken ordning de ska köras — som att rita ett flödesschema i förväg. Open Multi-Agent tar bort det steget: du skriver vad du vill uppnå och systemet räknar ut en plan vid körtid, kör steg parallellt när möjligt, och stannar för ditt godkännande vid känsliga beslutspunkter. Inbyggt överblicksläge visar vad varje agent gör i realtid, vilket är unikt bland liknande ramverk.

**Buzz-nivå:** Håller på att bli en grej — 6 900 GitHub-stjärnor, aktivt underhållet sedan april 2026.

**Testa:** https://github.com/open-multi-agent/open-multi-agent — README innehåller körklara exempelflöden.

### ODS — Lokal AI-stack med ett kommando (Osmantic)

**Vad det är:** En startpaket som med ett enda kommando sätter upp en komplett lokal AI-miljö: chatt-gränssnitt, modellrouter, dokumentsökning, flödesautomation och röst-TTS — automatiskt anpassad till din hårdvara.

**Varför intressant:** Att sätta ihop en lokal AI-stack innebär normalt att installera fem separata verktyg och konfigurera dem att prata med varandra. ODS paketerar Ollama (kör modeller lokalt), LiteLLM (router som väljer rätt modell), Open WebUI (chatt-gränssnitt), Qdrant (dokumentsökning), n8n (automatisering) och Kokoro TTS (röst) i ett enda kommando. Konfigurationen anpassas automatiskt utifrån hur mycket grafikkorts-minne du har. Allt stannar på din maskin — inga prenumerationer.

**Buzz-nivå:** Börjar fångas upp — under 6 000 GitHub-stjärnor, Apache 2.0-licens, aktivt underhållen.

**Testa:** https://github.com/Osmantic/ODS — ett kommando och hela stacken är igång, se README.

### AgentScope 2.0 (Alibaba)

**Vad det är:** Alibabas produktions-testade ramverk för multi-agent-system fick i augusti 2026 sin hittills största uppdatering: strukturerade pipelines, direktintegration mot Slack, DingTalk och Discord, och ett sand-boxat API för att köra agenter som molntjänst.

**Varför intressant:** AgentScope används i produktion internt hos Alibaba och är ett av de mer stabila alternativen till LangGraph och CrewAI. Version 2.0 riktar in sig på tre saker som saknades: möjligheten att kedja komplexa arbetsflöden i tydliga pipelines, att agenter direkt kan posta i teamets Slack eller Discord, och ett "Agent as a Service"-API som hanterar hela körnings-infrastrukturen. Det är nu det enda ramverk som har alla tre inbyggda i en sammanhängande plattform.

**Buzz-nivå:** Håller på att bli en grej — öppen källkod (Apache 2.0), produktionsanvänt, uppdatering publicerad aug 2026.

**Testa:** https://github.com/agentscope-ai/agentscope — `pip install agentscope` och kör exempelnotebooks.

### Open-AutoGLM (Zhipu AI)

**Vad det är:** Ett öppet ramverk för AI-agenter som kan se din Android-mobilskärm och sedan trycka, scrolla och skriva för din räkning — utan proprietärt API eller molnprenumeration.

**Varför intressant:** De kommersiella telefon-agenterna kräver att du betalar per session och skickar skärmdumpar till molnet. Open-AutoGLM kör lokalt via ADB — samma protokoll som används för app-testning — och behöver bara att du kopplar in telefonen via USB. Modellen är tränad att visuellt förstå skärmar och kan styra både Android och HarmonyOS (Huaweis system). Vikterna är fritt tillgängliga på HuggingFace och kan köras utan något konto hos Zhipu.

**Buzz-nivå:** Börjar fångas upp — MIT och Apache 2.0-licens, modellvikterna på HuggingFace, lanserat september 2026.

**Testa:** https://github.com/zai-org/Open-AutoGLM — koppla in din Android-telefon och följ installationsguiden.

## Specialgrejer & experiment

### OrchBench (arXiv:2607.25656)

**Vad det är:** Ett verktyg som bedömer hur bra ett multi-agent-arbetsflöde kommer att fungera — utan att faktiskt köra agenterna.

**Varför intressant:** Att testa om ett agent-arbetsflöde är välstrukturerat kostar normalt pengar i API-avgifter och tar tid. OrchBench simulerar hela körningen matematiskt och returnerar poäng: hur väl information bevaras mellan agenter, hur parallelliserat arbetsflödet är, förväntad slutkvalitet. Korrelerar 0,816 med riktiga Claude Code-körningar men använder bara 1,3 % av token-budgeten. Viktigaste lärdomen: antalet agenter spelar mindre roll än hur väl information förs vidare mellan dem — en insikt som kan spara mycket experimentering.

**Buzz-nivå:** Extremt tidigt — arXiv-preprint publicerat 28 juli 2026, ingen kodrelease ännu.

**Testa:** https://arxiv.org/abs/2607.25656 — läs preprinten och vänta på officiell kodrelease.

### ClawBench (TIGER-AI-Lab)

**Vad det är:** Ett realistiskt test som mäter hur bra webb-agenter egentligen klarar riktiga uppgifter på 143 levande produktionssajter — matbeställning, jobbansökningar, resebokningar.

**Varför intressant:** AI-agenter påstås klara 65–75 % av uppgifter i standardmiljöer. ClawBench testar samma agenter mot riktiga sajter och det bästa nuvarande resultatet är 33,3 % — de svagaste agenterna hamnar på 6 %. Det är inte ett nischtest utan ett uppvaknande: klyftan mellan marknadsförd prestanda och verkligheten är enorm. Testet förhindrar dessutom att agenter råkar genomföra riktiga köp under körning — ett problem som saknats i tidigare benchmarks. Nyttigt att känna till för alla som funderar på att automatisera webbaserade uppgifter.

**Buzz-nivå:** Börjar fångas upp — 635 GitHub-stjärnor, v0.8.0 den 30 juli 2026, citeras av Stanford, UC Berkeley och Google DeepMind.

**Testa:** https://github.com/TIGER-AI-Lab/ClawBench — kör mot din agent eller läs ledartavlan.

### Toolathlon (HKUST-NLP)

**Vad det är:** Det svåraste realistiska testet för AI-agenter som använder externa verktyg — 604 verktyg på 32 plattformar (Canvas, BigQuery, WooCommerce, Kubernetes), i snitt 20 verktygsanrop per uppgift.

**Varför intressant:** De flesta tester av AI-verktygsanvändning testar ett verktyg åt gången. Toolathlon testar de sammansatta arbetsflöden som dyker upp i verkligheten: flytta data från BigQuery till WooCommerce, logga i Kubernetes, skicka bekräftelse via e-post. Claude 4.5 Sonnet — i nuläget bästa modellen — klarar 38,6 %. DeepSeek-V3.2 stannar på 20,1 %. Det sätter ett ärligt mått på var AI faktiskt befinner sig för komplexa, sammankopplade uppgifter — och hur mycket arbete som återstår.

**Buzz-nivå:** Börjar fångas upp — 477 GitHub-stjärnor, ICLR 2026, verifierat 30 juni 2026.

**Testa:** https://github.com/hkust-nlp/Toolathlon — kör mot din agent eller läs resultaten.

### OpenMAIC (THU-MAIC, Tsinghua University)

**Vad det är:** Ett utbildningssystem drivet av specialiserade AI-agenter — en undervisar, en spelar motiverande klasskamrat, en fungerar som examinator — med interaktiv whiteboard och kodövningar.

**Varför intressant:** Vanliga AI-tutors är i princip en chatbot som svarar på frågor. OpenMAIC delar upp rollen i tre koordinerade agenter: en som strukturerar lektioner, en som utmanar med följdfrågor (som en engagerad klasskamrat), och en som bedömer förståelse och avgör när du är redo att gå vidare. Tanken är att lärandet förbättras när du måste formulera och förklara vad du förstår — inte bara ta emot information. Öppen källkod, körbar lokalt.

**Buzz-nivå:** Håller på att bli en grej — v1.0.0 lanserat 27 aug 2026, +9 400 GitHub-stjärnor på en vecka.

**Testa:** https://github.com/THU-MAIC/OpenMAIC — klona och följ installationsguiden.
