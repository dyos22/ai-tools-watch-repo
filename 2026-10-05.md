# AI-verktygsspaning — 5 oktober 2026

*Veckovis bevakning av nya och uppåtkommande AI-verktyg*

---

## Inledning

Veckans tema är *uthållighet* — i tre olika bemärkelser. Dels verktyg som sparar vad AI-agenter lärt sig (minne som faktiskt håller), dels system som gör att agenter kan krascha och ändå fortsätta exakt där de slutade, och dels ett helt nytt sätt att orkestrerar agentteam som om de vore Docker-behållare. Parallellt med det: ett kontorspaket som vägrar skicka dina dokument till molnet, och det enklaste sättet hittills att koppla Claude Code och liknande verktyg till mer än hundra externa tjänster på en gång.

## Gör Claude Code och andra AI-assistenter smartare

### pstack-claude — Cursors disciplin, nu för Claude Code

**Vad det är:** En installationsbar konfigurationsprofil som porterar Cursors berömda "pstack"-metodik — ett rigoröst sätt att arbeta i steg (spec → test → kod → granska) — till Claude Code, Codex, Gemini CLI och OpenCode.

**Varför det är intressant:** Cursor har länge haft rykte om sig att hålla sina agenter disciplinerade: planera innan du kodar, verifiera varje steg, kör tester innan du committar. pstack-claude ger samma systematik till alla andra kodningsagenter utan att du behöver byta verktyg. I praktiken märker du det som att agenten tar färre genvägar och gör färre onödiga saker.

**Buzz-nivå:** Börjar fångas upp — 442 GitHub-stjärnor, diskuteras i Claude Code-communityt och omnämns i flera AI-kodningsnewsletters.

**Testa:** [github.com/michael-denyer/pstack-claude](https://github.com/michael-denyer/pstack-claude) — installera en gång, alla agenter börjar automatiskt följa metodiken.

### Kage — AI-agentens minne lagras direkt i repot

**Vad det är:** Ett minnessystem för kodningsagenter (via MCP-standard) som sparar vad agenten lärt sig — buggar, workarounds, designbeslut — som vanliga textfiler direkt i ditt git-repo.

**Varför det är intressant:** De flesta minnesverktyg kräver ett databaskonto eller en molntjänst. Kage gör minnen till vanliga filer i repot: de versionshanteras, syns i pull requests och delas automatiskt med teamet via git utan extra steg. Det är ungefär som att agenten skriver en anteckningsbok som du kan läsa och redigera precis som vilken annan fil som helst.

**Buzz-nivå:** Extremt tidigt — 6 GitHub-stjärnor, men redan listad i de centrala MCP-katalogerna (awesome-mcp-servers, glama.ai). Konceptet fångas upp snabbt.

**Testa:** [github.com/kage-core/Kage](https://github.com/kage-core/Kage) — `npx kage` installerar MCP-servern, fungerar med Claude Code och andra MCP-kompatibla agenter.

### agenttrace — Vad kostade egentligen den där Claude Code-sessionen?

**Vad det är:** Ett lokalt terminalprogram som samlar historik från 14+ AI-kodningsagenter — Claude Code, Codex, Cursor, Gemini CLI, Cline, Aider med flera — och visar tokens, uppskattad kostnad, körtid och vilka verktygssteg som misslyckades.

**Varför det är intressant:** Det enda alternativet idag är att manuellt läsa loggar eller använda molnbaserade tjänster som skickar data vidare. agenttrace kör helt lokalt, stödjer flest agenter i en samlad vy och låter dig jämföra "var det billigare att låta Claude Code skriva det, eller Codex?".

**Buzz-nivå:** Börjar fångas upp — 101 GitHub-stjärnor, listat i SkillsLLM-registret, aktiv roadmap med planerat stöd för fler runtimes.

**Testa:** [github.com/luoyuctl/agenttrace](https://github.com/luoyuctl/agenttrace) — installera, kör `agenttrace` i terminalen.

## Verktyg, automation & infrastruktur

### GenOffice — AI-kontoret som stannar på din maskin

**Vad det är:** En öppen källkod AI-kontorssvit — Docs, Sheets, Slides, PDF, Markdown — som kör helt lokalt och redigerar riktiga .docx/.xlsx/.pptx-filer med inbyggd AI-assistans.

**Varför det är intressant:** Till skillnad från Microsoft 365 Copilot eller Google Docs med AI lämnar filerna aldrig din dator för den vanliga redigeringen. AI:n gör spårade ändringar som visas och kan ångras med ett klick, precis som vanlig spårad redigering i Word. PDF:er konverteras till redigerbara Office-filer utan molntjänst. Claude Code och andra agenter kan också styra det via ett kommandoradsgränssnitt — för den som vill automatisera dokumentarbete.

**Buzz-nivå:** Håller på att bli en grej — 8 630 GitHub-stjärnor på bara några veckor från lansering (31 juli 2026).

**Testa:** [github.com/genspark-ai/genoffice](https://github.com/genspark-ai/genoffice) — ladda ner, öppna ett Word-dokument, klicka på AI-ikonen.

### LobsterAI — Styr din AI-assistent varifrån du är

**Vad det är:** En skrivbordsapp (öppen källkod, NetEase Youdao) där en AI-agent med 28 inbyggda färdigheter och stöd för MCP-servrar kör lokalt på din dator — och som du kan nå och styra på distans via WeChat, Feishu, DingTalk eller Telegram från mobilen.

**Varför det är intressant:** De flesta skrivbordsagenter är bundna till datorn. LobsterAI låter agenten sitta hemma och jobba medan du skickar uppdrag från telefonen. Den kombinerar direkt åtkomst till filsystemet, terminalkörning och webbläsarautomation i en app, sparar allt i en lokal SQLite-databas och kräver inget molnkonto för basanvändning.

**Buzz-nivå:** Håller på att bli en grej — 6 085 GitHub-stjärnor sedan lansering i februari 2026.

**Testa:** [github.com/netease-youdao/LobsterAI](https://github.com/netease-youdao/LobsterAI) — ladda ner appen, koppla Telegram och ge agenten sitt första uppdrag.

### Klavis — En brygga till 100+ tjänster för dina agenter

**Vad det är:** En plattform med 100+ färdiga integrationsmoduler (Gmail, Slack, GitHub, Notion, Jira…) som kopplar AI-agenter till externa tjänster via MCP-standarden, med OAuth-inloggning hanterat centralt.

**Varför det är intressant:** I stället för att konfigurera varje tjänst separat hanterar Klavis inloggning och routning centralt. Det är som att ha ett "eluttag" som agenten pluggar in i, och sedan kan nå alla tjänster via samma uttag. Inkluderar också "Strata" — en funktion som hjälper agenten prioritera vilken information den ska använda när kontexten (det agenten håller i minnet) börjar bli full.

**Buzz-nivå:** Håller på att bli en grej — 5 808 GitHub-stjärnor sedan april 2025, aktivt underhållet.

**Testa:** [github.com/Klavis-AI/klavis](https://github.com/Klavis-AI/klavis) — kör via Docker eller SDK, koppla in Claude Code via MCP-konfigurationen.

### agent-compose — Docker Compose för agentteam

**Vad det är:** Ett kommandoradsverktyg (öppen källkod, Go) som låter dig deklarera ett team av AI-agenter i en YAML-fil — exakt som man deklarerar Docker-behållare — och köra dem parallellt i isolerade sandlådor.

**Varför det är intressant:** Tanken är bekant för alla som jobbat med Docker: du skriver `agent-compose.yml` och bestämmer vilken agent som kör vilken provider (Claude Code, Codex, Gemini…), hur de schemaläggas och vilka rättigheter de har. API-nycklar stannar hos daemonen och exponeras aldrig inuti gäst-miljön. Mentala modellen (en fil beskriver hela systemet) är ett av de tydligaste sätten hittills att orkestrerra flera specialistagenter utan handpåläggning.

**Buzz-nivå:** Extremt tidigt — 231 GitHub-stjärnor, ~3 stjärnor/dag sedan juni 2026. Växer stadigt.

**Testa:** [github.com/chaitin/agent-compose](https://github.com/chaitin/agent-compose) — installera daemonen, skriv en agent-compose.yml, kör `agent-compose up`.

### OrcaReplay — Spela in en agentkörning, spela upp gratis

**Vad det är:** En öppen källkod motor som spelar in fullständiga AI-agentkörningar — inklusive varje kommando, filsystemsändring, MCP-anrop och webbanrop — och kan återspela dem byte-för-byte utan att kalla på modellen igen.

**Varför det är intressant:** Agentdebugning är svår eftersom körningar inte är reproducerbara och varje ny körning kostar pengar. OrcaReplay gör dem deterministiskt reproducerbara: du spelar in en gång och kan sedan spola tillbaka, granska vad som gick fel, och testa om en annan modell hade gjort rätt — allt utan extra kostnad. Det liknar vad Playwright har gjort för webbtester, fast för AI-agenter.

**Buzz-nivå:** Börjar fångas upp — 149 GitHub-stjärnor vid HN-lansering i september 2026, täckt av AiThority.

**Testa:** [github.com/Continuum-AI-Corp/OrcaReplay](https://github.com/Continuum-AI-Corp/OrcaReplay) — installera, starta inspelningsläget, kör din agent, replay när som helst.

### Observal — Kontrollpanelen som samlar alla agenter

**Vad det är:** En självhostad kontrollpanel och observabilitetsplattform (öppen källkod, BlazeUp AI) som samlar agentregister, sessionstelemetri, session-replay och ett administrativt granskningsgränssnitt i ett enda lokalt körd UI.

**Varför det är intressant:** Till skillnad från molntjänster som LangSmith eller LangFuse kör allt lokalt via Docker Compose utan externa beroenden. Du kan publicera, hitta och installera agenter och MCP-servrar via ett UI, felsöka agenters beteende via turn-by-turn-replay, och generera konfigurationsfiler för Claude Code, Cursor och andra automatiskt. Tänk "ett ställe att hantera alla agenter" i stället för separata konfigurationsfiler utspridda överallt.

**Buzz-nivå:** Håller på att bli en grej — 2 227 GitHub-stjärnor, 462 forks, v1.10.3 i juli 2026.

**Testa:** [github.com/BlazeUp-AI/Observal](https://github.com/BlazeUp-AI/Observal) — `docker compose up` så är dashboarden på localhost.

## Specialgrejer & experiment

### ds4 — DeepSeek V4 Flash på din Mac, skrivet av Redis-skaparen

**Vad det är:** En lokal inferensmotor i C för DeepSeek V4 Flash — en av de kraftigaste öppna AI-modellerna just nu (284 miljarder parametrar i en arkitektur som gör den körbar lokalt) — skriven av Salvatore Sanfilippo, skaparen av Redis.

**Varför det är intressant:** Det är inte en generisk modellladdare utan ett singelsyftesverktyg: en modell, optimerad för en hårdvarutyp. På MacBook Pro M3 Max med 128 GB RAM: 26 texttokens per sekund vid energisnål inställning, 50 watt toppeffekt. Vision-stöd (bilder) tillkom i september 2026. För den som vill köra en riktigt kapabel modell lokalt utan molnanslutning är det det rakaste alternativet för Apple Silicon just nu.

**Buzz-nivå:** Håller på att bli en grej — ~3 005 GitHub-stjärnor, trendade på Hacker News, +211 stjärnor på en dag när GPU-stödet lanserades.

**Testa:** [github.com/antirez/ds4](https://github.com/antirez/ds4) — kompilera och kör; kräver Mac med Apple Silicon och minst 64 GB RAM för full modell.

### Lians — Minne som faktiskt vet när något ändrades

**Vad det är:** Ett MCP-minnessystem för AI-agenter med "bitemporalt" minne — det vill säga att det skiljer på *när något hände* och *när agenten fick veta det* — med deterministisk fakta-ersättning och manipuleringssäker revisionshistorik.

**Varför det är intressant:** Alla existerande agentminneslösningar är monotona: man kan bara lägga till fakta, aldrig korrigera historiken korrekt. Lians låter agenten ersätta föråldrade fakta (inte bara skriva över dem), rekonstruera sitt eget tillstånd vid en given tidpunkt och upprätthålla informationsbarriärer — tekniker som länge funnits i databaser för reglerade branscher (bank, vård) men som nu dyker upp för agentminnen. Lagras lokalt i `~/.lians/mcp.db` utan konto, Docker eller API-nyckel.

**Buzz-nivå:** Extremt tidigt — 6 GitHub-stjärnor men officiellt listad i MCP Registry och mcpservers.org; SDK publicerat på PyPI (lians-sdk 0.5.0).

**Testa:** [github.com/Lians-ai/Lians](https://github.com/Lians-ai/Lians) — `pip install lians-sdk`, konfigurera som MCP-server i Claude Code.
