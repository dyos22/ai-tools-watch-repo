## Gör Claude Code och andra AI-assistenter smartare

### Semble — kodsökning som inte spränger kontextfönstret

**Vad det är:** Ett kodsökningsbibliotek byggt specifikt för AI-agenter — returnerar exakt rätt kodstycken istället för hela filer.

**Varför det är intressant:** Vanliga sökverktyg (grep, läs hela filen) tvingar agenten att sluka upp till 99 % mer kontext än nödvändigt. Semble indexerar ett helt kodbas på 500 millisekunder och svarar på frågor på 1 millisekund, helt lokalt utan internetuppkoppling och utan GPU. Det pluggar in direkt som en MCP-server i Claude Code, Cursor och Codex — agenten "frågar" istället för att läsa. Praktisk konsekvens: längre arbetspass utan att agenten tappar bort sig i ett överfyllt minne.

**Buzz-nivå:** Håller på att bli en grej — 6 100 GitHub-stjärnor, MIT-licens, september 2026.

**Testa:** https://github.com/MinishLab/semble — installera via pip, kör `semble init` i ditt repo och koppla MCP-servern till Claude Code.

### MCPlex — smart dirigent för alla dina Claude Code-tillägg

**Vad det är:** En mellanhand (proxy) som sitter mellan Claude Code och alla dina installerade MCP-tillägg, och väljer automatiskt vilka verktyg agenten faktiskt behöver för varje uppgift.

**Varför det är intressant:** Har du installerat många MCP-tillägg i Claude Code händer det att agentens "verktygsminne" fylls med 50 000 teckens långa listor av verktyg den aldrig behöver för just den uppgiften — rent slöseri. MCPlex väljer ut enbart relevanta verktyg per fråga (70–90 % besparing) och ger dig en liten kontrollpanel på din dator där du ser vad som händer. Det stödjer också åtkomstkontroll (vem/vad får använda vilket verktyg) och sparar svar för snabbare upprepade anrop.

**Buzz-nivå:** Extremt tidigt — bara 12 GitHub-stjärnor, men problemet det löser är välkänt och kostsamt för alla med många MCP-tillägg. Aktivt listat på Glama MCP Registry, senaste version v0.7.1 med säkerhetshärdning.

**Testa:** https://github.com/ModernOps888/mcplex — installera via `pip install mcplex-backplane` och konfigurera som proxy i Claude Code.

### agentproto/ts — CI/CD-tänk för agent-arbetsflöden

**Vad det är:** Ett TypeScript-ramverk som låter dig skriva ett agentsteg som ett recept — varje steg anger vilken modell, hur hårt den ska arbeta, och vilka verktyg den får använda — och lägger in kvalitetskontroller mellan stegen.

**Varför det är intressant:** En agent som kör fritt kan ta fel väg och det märks inte förrän sent. agentproto/ts tvingar in checkpoint-kontroller (shell-kommandon som kontrollerar att mellanresultatet håller måttet) och konfigurerbara omförsök-strategier — exakt som ett automatiserat testflöde i mjukvaruutveckling men för agenter. Stödjer godkännandeflöden där en människa måste klicka OK på känsliga steg. Tänk det som ett säkerhetsräcke runt autonoma agenter i produktionsmiljöer.

**Buzz-nivå:** Extremt tidigt — 6 GitHub-stjärnor, men lanserades 6 september 2026 och är aktivt underhållet. MIT-licens.

**Testa:** https://github.com/agentproto/ts — TypeScript-paket, dokumentation i README.

## Verktyg, automation & infrastruktur

### Monid — en enda nyckel till 2 000+ agentverktyg

**Vad det är:** En aggregatortjänst som ger din AI-agent tillgång till 2 000+ externa verktyg från 72 leverantörer — sökning, webbskrapning, kontakt- och företagsdata, sociala plattformar, marknadsdata — via en enda adress och ett enda konto.

**Varför det är intressant:** Att koppla en agent till externa verktyg kräver normalt separata konton, API-nycklar och integrationskod för varje tjänst. Monid gör det till en rad kod — jämför med hur OpenRouter samlade ihop alla AI-modeller till ett enda API, fast för verktyg istället för modeller. Prismodellen är inbyggd (flat, per-anrop eller per-enhet beroende på verktyg), och koden för varje connector är öppen källkod under MIT.

**Buzz-nivå:** Håller på att bli en grej — #1-rankad lansering på Product Hunt 4 september 2026 med 456 röster, open-sourcades 16 september 2026. Bara 164 GitHub-stjärnor men troligtvis starkt tillväxtmomentum.

**Testa:** https://github.com/monid-ai/monid — börja med dokumentationen för att se vilka av de 72 leverantörerna som passar ditt användningsfall.

### Firstmate — dirigenten för ett team av parallella agenter

**Vad det är:** Middleware som låter en huvudagent distribuera uppgifter till ett helt gäng parallella subagenter i isolerade kopior av projektet, och slår sedan ihop deras arbete automatiskt.

**Varför det är intressant:** Claude Code och liknande agenter arbetar i ett fönster i taget. Firstmate spawnar agenter per uppgift (ship-läge för leverans, scout-läge för utforskning), hanterar git-baserad isolering och merge-rättigheter automatiskt, och inkluderar en opt-in Relay som låter agenter svara på omnämnanden på X och Discord. Mer operativt inriktad än rena multi-agent-ramverk — tänkt som ett "agentoperationscenter" snarare än ett kodbibliotek.

**Buzz-nivå:** Håller på att bli en grej — 6 200 GitHub-stjärnor, trending den här veckan på GitHub Shell-listan.

**Testa:** https://github.com/kunchenguid/firstmate — konfigurationsfil i YAML, stöder Claude Code och OpenAI Codex.

### PI-Desktop — lokal agentarbetsyta utan molnberoende

**Vad det är:** En skrivbordsapp (Electron + Rust) som samlar AI-kodningsagenter i ett gränssnitt — modell-agnostisk, helt lokal, med separata lägen för autonomt arbete, granska-och-godkänn och målstyrning.

**Varför det är intressant:** Devin och liknande agentverktyg är molnbaserade och hanterade av leverantören. PI-Desktop kör allt på din maskin — sessioner, historik, konfiguration — och stödjer OpenAI, Anthropic, lokala modeller och alla kompatibla API:er utan att binda dig till en enda leverantör. Plugin-marknad med stöd för MCP-servrar och subagenter. Tydlig konkurrent för den som vill ha full kontroll.

**Buzz-nivå:** Börjar fångas upp — 4 100 GitHub-stjärnor, omnämnd i AI Open Source Trends-rapporten 10 september 2026.

**Testa:** https://github.com/vastsa/PI-Desktop — installationsfiler för Mac, Windows och Linux på GitHub Releases.

### Ontheia — self-hosted AI-plattform för hela teamet, ett Docker-kommando

**Vad det är:** En komplett plattform för multi-agent-arbete med inbyggt stöd för MCP, flerleverantörsmodeller (Claude, GPT, Gemini, Grok, Ollama), rollbaserad åtkomstkontroll och visuell workflow-byggare — allt paketerat för att köras på din egna server.

**Varför det är intressant:** Hosted-only alternativ (Zapier AI, Relevance AI) innebär att alla konversationer och data lagras hos leverantören. Ontheia kör i din infrastruktur, stödjer PostgreSQL-baserad säkerhet per rad (varje användare ser bara sina egna data), inbyggd sök i dokument via en lokal vektordatabas, och agenter kan delegera till sub-agenter. Installeras med en enda rad: `curl -fsSL https://get.ontheia.ai | bash`.

**Buzz-nivå:** Extremt tidigt — bara 11 GitHub-stjärnor, men AGPL-3.0-licens och listad som kompatibel klient på mcpservers.org. Högt ambitiöst scope för ett nystartat projekt.

**Testa:** https://github.com/Ontheia/ontheia — Docker-baserad installation, engelskspråkig dokumentation.

### DeskcommCRM — ett öppet CRM med agenter som kan stänga affärer autonomt

**Vad det är:** En open source AI-säljplattform med inbyggda agenter som kan sköta WhatsApp-konversationer, kvalificera inkommande leads och driva ärenden framåt — utan att en människa behöver vara med i varje steg.

**Varför det är intressant:** Traditionella CRM-system (HubSpot, Salesforce) kräver att en människa hanterar varje konversation. DeskcommCRM kombinerar klassisk CRM-funktionalitet (Kanban-pipeline, automatiseringsregler) med RAG-baserade AI-agenter som agerar i WhatsApp-konversationer. En-kommando-deploy via Docker. Byggt med brasiliansk marknad (LGPD-kompatibel) som primärt mål men arkitekturen är generell.

**Buzz-nivå:** Håller på att bli en grej — 3 100 GitHub-stjärnor, 726 forks, 4 860 commits, trending TypeScript-projekt denna vecka.

**Testa:** https://github.com/melgarafael/DeskcommCRM — Docker Compose, kräver WhatsApp Business API-konto.

## Specialgrejer & experiment

### Hyperresearch — AI-agenten som skriver en granskningsbar rapport från grunden

**Vad det är:** En agentstyrd research-pipeline som tar en enskild fråga och producerar ett strukturerat, källhänvisat dokument via ett 16-stegs-flöde — inklusive hämtning av fulltext från akademiska källor.

**Varför det är intressant:** Enkla "research agent"-verktyg söker och sammanfattar. Hyperresearch håller koll på 250+ källor per körning, extraherar fulltext från paywallad akademisk litteratur via öppna repositorier, och bygger upp ett sökbart kunskapsvalv som sparas mellan sessioner. Avbrutna jobb kan återupptas. Primärt byggt för Claude Code-miljöer och stödjer Gemini, OpenAI och Ollama som alternativ.

**Buzz-nivå:** Håller på att bli en grej — 3 400 GitHub-stjärnor, trending Python-projekt denna vecka.

**Testa:** https://github.com/jordan-gibbs/hyperresearch — pip-installation, konfigurera API-nyckel och kör `hyperresearch "din fråga"`.

### Claude-Red — ett bibliotek med säkerhetsperspektiv direkt i Claude

**Vad det är:** En samling av 78 specialiserade kunskapspaket (SKILL.md-filer) som ger Claude expertperspektiv inom offensiv säkerhet — SQL-injektioner, skalkod, EDR-kringgående och exploit-utveckling — för auktoriserade säkerhetstestare.

**Varför det är intressant:** En säkerhetsgranskare som vill använda Claude som tankeverktyg behöver annars formulera detaljerade och specifika uppmaningar för varje attack-yta. Claude-Red paketerar metodologisk expertis per domän som en skill som laddas när den behövs — och är explicit avgränsad till auktoriserade uppdrag, bug bounty-program och CTF-tävlingar. Det minskar friktionen för legitima säkerhetsteam.

**Buzz-nivå:** Håller på att bli en grej — 5 900 GitHub-stjärnor, trending Python-projekt denna vecka.

**Testa:** https://github.com/SnailSploit/Claude-Red — kräver Claude API-nyckel; README innehåller dokumentation per attack-domän.

### Onset MCP — agenten håller dina release notes uppdaterade

**Vad det är:** En MCP-server som kopplar Claude Code och Cursor direkt till release notes-plattformen Onset — agenten kan läsa, skapa och redigera versionsbeskrivningar, men publicering kräver ett separat, manuellt steg.

**Varför det är intressant:** Release notes är en av de saker som nästan alltid skrivs för sent och med minst entusiasm. Onset MCP låter agenten hålla dem uppdaterade i realtid medan kod skrivs, utan manuellt copy-paste. Publiceringen — mejl och Slack-utskick till prenumeranter — är medvetet utanför agentens räckvidd. One-click install för Claude, Claude Code, Cursor och VS Code.

**Buzz-nivå:** Börjar fångas upp — 105 Product Hunt-röster vid launch 2 september 2026. Täckt av ChatGate.ai.

**Testa:** https://mcp.onset.io — OAuth 2.1-autentisering, installationsknapp direkt på sidan.
