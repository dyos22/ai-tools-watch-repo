# AI-verktygsspaning — 2026-07-25

## Inledning

Veckans spaning har ett tydligt tema: *AI-agenter i flock*. Allt fler kör inte en agent utan fem, tio, eller ett helt team av dem parallellt — och nu börjar managementproblemen träda fram. Hur håller du koll på vad de alla gör? Hur stoppar du ett felsteg innan det gör skada? Hur betalar du inte en förmögenhet i onödiga tokens när agenterna laddar in mer kontext än de behöver? Tre separata verktyg adresserar de frågorna den här veckan, var och en från ett annat håll. Parallellt dyker det upp den mest handfast demonstrerade "meta-AI" hittills: en agent som lärde sig träna andra agenter — med mätbar och generaliserbar framgång.

## Gör Claude Code och andra AI-assistenter smartare

### Ratel

**Vad det är:** Ett bibliotek som gör att en AI-agent automatiskt väljer ut bara de verktyg som är relevanta för den aktuella frågan, istället för att ladda in sin hela verktygskatalog vid varje anrop.

**Varför det är intressant:** Om Claude Code har 50 integrerade verktyg — filsystem, GitHub, databas, kalender, API:er — och du ber den om en enkel filändring, skickar den i dag information om alla 50 till modellen. Det slösar tokens och gör agenten sämre på att fokusera. Ratel fungerar som ett snabbsökningsindex: agenten letar bland verktygsbeskrivningarna och injicerar bara de 3–5 som faktiskt behövs. Ingen databas att driftsätta, inga molnberoenden. Fungerar direkt med Vercel AI SDK och Pydantic AI.

**Buzz-nivå:** Börjar fångas upp — 344 GitHub-stjärnor, Show HN juli 2026, Apache 2.0.

**Testa:** https://github.com/ratel-ai/ratel — ett installationskommando, sedan wrappar du din befintliga verktygslista med `ratel.catalog(tools)`.

### Proliferate

**Vad det är:** En öppen IDE (skrivbordsapp och webb) som kör Claude Code, Codex, OpenCode och andra kodningsagenter parallellt i isolerade projektgrenar — med inbyggt gransknings- och sammanslagningsflöde.

**Varför det är intressant:** Cursor och Windsurf kör en agent åt gången och du sitter och väntar. Proliferate vänder på det: starta fem agenter på samma problem, se dem alla arbeta parallellt, och välj eller kombinera det bästa resultatet — ungefär som att tilldela en uppgift till fem juniorutvecklare och sedan granska deras pull requests. Agenter kan dessutom delegera deluppgifter till varandra. Jämfört med Orca (som täcktes i rapporten 2026-07-15) är Proliferate öppen källkod under AGPL-licens utan leverantörslåsning.

**Buzz-nivå:** Extremt tidigt men aktivt — 151 GitHub-stjärnor, AGPL-3.0, 1 916 commits, molnbeta med rullande access.

**Testa:** https://github.com/proliferate-ai/proliferate / https://proliferate.com — `npx proliferate` eller ladda ned skrivbordsappen.

### aegis

**Vad det är:** En tilläggsserver till Claude Code och Cursor som automatiskt hittar och injicerar precis rätt arkitekturdokument för de filer du arbetar med — utan gissningar, utan sökning.

**Varför det är intressant:** Alla befintliga lösningar för att ge agenten rätt kontext (semantisk sökning, likhetsrankering) är osäkra — de hittar *förmodligen* rätt dokument. Aegis arbetar deterministiskt istället: den beräknar exakt vilka dokument som krävs utifrån projektets beroendekarta, på samma sätt som en kompilator vet exakt vilka filer som behöver inkluderas. Agenten kan dessutom inte ändra arkitekturregler utan ett mänskligt godkännande via en kodgranskning — beslut om infrastruktur förblir mänskliga.

**Buzz-nivå:** Extremt tidigt — 108 GitHub-stjärnor, Show HN (item 48741332), ISC-licens.

**Testa:** https://github.com/fuwasegu/aegis — lägg till som MCP-server i din agentens konfiguration.

### tlbx

**Vad det är:** En webbapp som låter dig se och styra AI-kodningsagenter som kör på din hemmadator eller server, från vilken webbläsare eller telefon som helst — utan molntjänst emellan.

**Varför det är intressant:** Problemet uppstår när du vill att Claude Code ska köra på din kraftfulla hemmadator (med tillgång till ditt repo, dina verktyg och dina credentials) medan du är på språng. tlbx löser det: agenten kör på din maskin, du styr den via webbläsaren på din telefon. Sessioner är persistenta — stänger du webbläsaren fortsätter agenten jobba. Ingen molntjänst behövs: du väljer din egen nätverksväg (Tailscale, VPN, Cloudflare Tunnel). Stöder filuppladdning och skärmdumpar direkt in i agentsessionen. Projektet är tekniskt moget (3 343 commits) och nyligen döpts om och riktar sig nu specifikt mot AI-agentanvändning.

**Buzz-nivå:** Börjar fångas upp — 96 GitHub-stjärnor, AGPL-3.0.

**Testa:** https://github.com/tlbx-ai/tlbx — `docker run -p 7681:7681 tlbxai/tlbx`, anslut sedan via webbläsare.

## Verktyg, automation & infrastruktur

### AgentTeams

**Vad det är:** En orkestreringsplattform (Apache 2.0) för team av AI-agenter — en Manager-agent koordinerar Worker-agenter (Claude Code, OpenCode m.fl.) via självhostade chatkanaler som du kan följa i realtid.

**Varför det är intressant:** Det unika med AgentTeams är hur transparensen är inbyggd: istället för ett proprietärt dashboard kommunicerar agenterna via Matrix — ett öppet, krypterat chattprotokoll. Varje agentinteraktion dyker upp som ett meddelande i en kanal du kontrollerar och kan läsa live, ungefär som att följa ett helt team-chat där alla deltagarna råkar vara AI-agenter. Jämfört med CrewAI och AutoGen krävs inget Python för att starta ett agentteam. Stöder Kubernetes för de som vill driftsätta i stor skala. Heter sedan v1.2.0 AgentTeams — lanserades ursprungligen under arbetsnamnet HiClaw.

**Buzz-nivå:** Håller på att bli en grej — 5 200 GitHub-stjärnor, 613 forks, Apache 2.0, v1.2.0-beta.1 släppt 17 juli 2026.

**Testa:** https://github.com/agentscope-ai/AgentTeams — installera med ett enda curl-kommando eller via Helm-chart för Kubernetes.

### klaw.sh

**Vad det är:** En kommandoradsklient (en liten Go-binär) som hanterar AI-agenter med samma typ av kommandon som Kubernetes använder för servrar: `klaw get agents`, `klaw logs`, `klaw describe` — med schemaläggning, namnrymder och stöd för 300+ AI-modeller.

**Varför det är intressant:** Kubernetes löste problemet med att köra och hålla koll på tusentals applikationer. klaw.sh gör samma sak för AI-agenter: du delar upp dem i projektnamnrymder, sätter tidscheman, routar förfrågningar till rätt modell och ser allt från ett enkelt CLI. Till skillnad från liknande verktyg som kräver ett fullständigt Kubernetes-kluster är klaw.sh en enda liten binärfil som körs var som helst. Gratis för personligt bruk.

**Buzz-nivå:** Börjar fångas upp — 634 GitHub-stjärnor, Show HN med 400+ poäng vid lansering i februari 2026.

**Testa:** https://klaw.sh — ladda ned binären, kör `klaw init` och konfigurera dina modell-providers.

### Alterion Draco

**Vad det är:** En kontrollpunkt som sitter osynligt mellan dina AI-agenter och din infrastruktur och blockerar, loggar eller eskalerar riskfyllda handlingar i realtid — utan att du behöver ändra ett enda anrop i koden.

**Varför det är intressant:** Alla de stora agent-plattformarna fokuserar på att *bygga* agenter, inte på att *styra* dem när de väl kör i produktion. Draco fyller det gapet: det analyserar agentens *avsikt* — inte bara vad den faktiskt körde — och verkställer organisationspolicyer i realtid. Speciellt relevant just nu: EU AI Act:s krav på high-risk AI-system trädde i kraft i augusti 2026, och Draco är ett av de få verktygen som adresserar specifikt agentarbetsflöden, inte bara statiska modeller. Grundat av ex-McKinsey och ex-VP Engineering Google.

**Buzz-nivå:** Extremt tidigt — lanserades 16 juli 2026, enterprise SaaS. Täckt av PR Newswire, Yahoo Finance och Morningstar vid lansering.

**Testa:** https://alterion.ai — demobegäran via webbplatsen; plattformen ansluts som ett proxylager utan kodändringar.

### Vaara

**Vad det är:** Ett Python-bibliotek som automatiskt skriver en manipuleringssäker, kryptografiskt signerad logg av varje åtgärd en AI-agent tar — och kan blockera eller eskalera enskilda handlingar baserat på egna policyer.

**Varför det är intressant:** EU AI Act kräver dokumentation på agent-exekveringsnivå (artikel 12), inte bara modellnivå. Vaara löser det med ett enda anrop (`@vaara.govern`) som wrappar agentens verktyg — ingen ny infrastruktur behövs. Loggen är kedjad med kryptografiska hash (ändrar man en rad syns det omedelbart) och förankrad i datorns säkerhetschipp (TPM 2.0), vilket gör den verifierbar av en extern revisor utan tillgång till ditt system. Det enda öppna projektet som kombinerar policy-styrning i realtid med hårdvaruförankrad revision.

**Buzz-nivå:** Extremt tidigt — 10 GitHub-stjärnor, AGPL-3.0. PyPI-paket tillgängligt. AMD AI Developer Program-testimonial maj 2026. Konceptuellt unikt inom EU AI Act-compliance för agentmiljöer.

**Testa:** https://github.com/vaaraio/vaara — `pip install vaara`, wrappa sedan agentens verktygsanrop med `@vaara.govern(policy="eu-ai-act")`.

## Specialgrejer & experiment

### ai-trains-ai

**Vad det är:** Ett öppet experiment där en AI-agent tränas med förstärkningsteknik att designa och köra träningsjobb för andra AI-modeller — med mätbar framgång på riktiga GPU:er.

**Varför det är intressant:** Föreställ dig en lärare som inte undervisar ämnen utan undervisar i *hur man lär ut* ämnen — och gör det bättre och bättre för varje lektion. Det är vad ai-trains-ai demonstrerar i praktiken: en yttre AI-loop tränas att bli bättre på att designa träningsprocesser för inre AI-loopar. Agentens belöning steg från ~0,0 till ~0,63 på 54 iterationer, och förmågan generaliserade till problem agenten aldrig sett. Total kostnad för hela det publicerade experimentet: ungefär 1 275 dollar. Den tränade "läraragenten" finns publik på Hugging Face. Hittades oberoende av två av spaningens tre agenter — stark signal.

**Buzz-nivå:** Börjar fångas upp — 221 GitHub-stjärnor, Show HN (item 48905919) 20 juli 2026, MIT-licens.

**Testa:** https://github.com/Danau5tin/ai-trains-ai — README beskriver hela experimentupplägget och kostnadsfördelningen. Kräver API-nyckel och GPU-krediter för fullständiga körningar.

### rigorix-oss

**Vad det är:** En körningsmotor (skriven i Rust) som tar en naturlig språkuppgift — "lägg till enhetstester för autentiseringsmodulen" — kompilerar den till ett inspekterbart flödesschema och exekverar den inom definierade behörighets- och budgetgränser.

**Varför det är intressant:** Alla dagens kodningsagenter (Claude Code, Cursor, Codex) kör öppna loopar där nästa steg är oförutsägbart — du vet inte vad agenten kommer att göra förrän den gjort det. Rigorix separerar *planering* från *exekvering*: planen är en inspekterbar fil du kan granska och godkänna innan agenten börjar. Varje körningssteg loggas med kryptografiska tidsstämplar, vilket gör det spårbart för compliance och CI/CD-pipelines. Ett tidigt men konceptuellt intressant alternativ till promptbaserade guardrails.

**Buzz-nivå:** Extremt tidigt — 17 GitHub-stjärnor, lanserat juli 2026, dual-licensierat MIT/Apache.

**Testa:** https://github.com/arman-jalili/rigorix-oss — `cargo install rigorix`, sedan `rigorix run "din uppgift"` i projektmappen.

### PaperOrchestra

**Vad det är:** En pipeline av fem koordinerade AI-agenter (planering, litteraturöversikt, figurgenerering, skrivande och raffinering) som tar ostrukturerade anteckningar och producerar ett komplett vetenskapligt manus.

**Varför det är intressant:** Baserat på ett Google-forskningspapper (arXiv:2604.05018, april 2026) men implementerat som en community-version som delegerar allt arbete till den kodningsagent du redan har (Claude Code, Cursor, Aider m.fl.) — utan separata API-nycklar eller ny konfiguration. Du kör ett slash-kommando och agenterna tar över: de söker litteratur, ritar figurer, skriver, citerar och förfinar i en koordinerad kedja. Fungerar lika bra för djupa utredningar och långa rapporter som för akademiska papper.

**Buzz-nivå:** Börjar fångas upp — 616 GitHub-stjärnor, baserat på Google-forskning april 2026, aktiv community-implementering.

**Testa:** https://github.com/Ar9av/PaperOrchestra — klona repot och kör `/paperorchestra` som ett slash-kommando i din befintliga kodningsagent.
